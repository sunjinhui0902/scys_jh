## 文本与制作接口

单集交给现有管线的文件为各集 `01_文案与分镜/口播文案.md`。总案供阅读，不能把五集总案直接送进单集解析器。

本版已按现有解析器使用准确标题 `## 顶部固定主标题`、`## 纯净口播文案`，并将固定书图写为 `复用固定资产: book_01.png` 等形式。每条九镜，镜头01～06对应各自 `shot_01`～`shot_06`，镜头07～09对应三张公共书图。

| 项目 | 本版约定 |
|---|---|
| 配音 | `zh-CN-YunjianNeural`，语速 `-8%`、音调 `-6Hz`；不再同时写1.1倍速 |
| 音频文件 | 现有管线输出 `03_配音音频/voice_master.mp3`，不预写不存在的 `voiceover.wav` |
| 配乐 | `01_配音与音色库/背景音乐库/bgm_shili_guofeng.mp3`；BGM `-13dB`、人声 `+3dB`作为现有基准，以实际试听调整 |
| 气口 | 依句意、问答和感情停顿；字幕分行另处理，不把口播切成机械的固定字数 |
| 时长 | 当前每条132～143个汉字，不含标点。未合成音频，实际时长留空；不凭字数许诺固定秒数与完播效果 |
| 额外音效 | 本版不挂提示音，不依赖原案未确认的 `ding.mp3` |
| 工程版本 | 使用本批独立目录和独立草稿名，进入制作时仍调用现有 `scripts/fast_draft_pipeline.py` |
| 换图 | 素材到齐后调用现有 `apply-images`；当前实现会重建草稿，不宣称仅改路径或承诺固定3秒 |

需要真实器物、砖铭、彩绘和水流地理的镜头，先准备对应参考；普通家庭、田野氛围及概念插画可按提示词生成。所有AI示意标识、字幕、箭头和中文标签由后期添加，生成图片本体保持无新增文字。每个最终提示词已经包含本镜约束，不再批量附加一套人物或场景要求。

本轮没有启动原文中的定时器、跨Agent唤醒、出图或草稿任务。后续若开始实际视频制作，按既有批量出图标准归档，并在出图期间并行初始化工程；“已写好提示词”不记为“图片已就绪”。

如果把五条剪成一条连续合辑，应删去前四条重复的商品邀请，在最后统一引书，并按合辑音频重排分镜；当前交付默认五条独立短片。

# 五城图片交付与素材来源

2026-10-23；依据同目录《下集五城_修订全案.md》制作。

**已齐30个内容镜头位置，均为1080×1920；22张内置生图结果（7张文生图、15张参考图编辑），8个真实照片排版位置。成都03、04按原案复用同一底图，不算两张不同照片。三张书图原始字节与尺寸保留，跨五集复用15次。**

本批为图片素材交付，不是成片验收。参考图编辑仍属于AI画面，不冒充现场摄影。

## 使用入口

- 各集 `02_分镜视觉素材/shot_01.png`～`shot_06.png` 为本集六个内容画面。
- 各集 `book_01.png`～`book_03.png` 为公共商品图的原字节复制。
- 本批 `images/shot_01.png`～`shot_30.png` 依五城顺序连续编号；每六张一城。
- `preview.jpg` 为总览；`images.zip` 为主图片包，内有编号图片、三张书图、提示词与校验清单。

- 8个真实照片排版位置没有AI重绘，保留来源文件；小图不放大。

- 初始30条Prompt逐字沿用原JSON，与Markdown一致；参考素材按镜头绑定。参考编辑通过独立的标准调度函数提交，不给Prompt追加全局人物设定。

- 本批T1含真实参考检索、下载及照片排版等待，不是纯模型渲染耗时；T3包含目检、来源整理与打包，按实际计时，未达目标也如实保留。

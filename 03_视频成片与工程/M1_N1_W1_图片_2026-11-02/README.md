## N1参考与使用边界

N1为AI绘制的教学概念示意图，无比例尺与精确地理边界，不作为现场照片或测绘图。成片后期须另加“示意图”与必要部位标注，当前无字底图按用户要求不烧入文字。

结构参考：[四川省地方志工作办公室网站所载渠首工程资料](https://www.scdfz.org.cn/Upload/main/ContentManage/Article/File/201701102113255732.pdf)，PDF第6页、印刷第179页，图2-5“1982年都江堰渠首工程布置图”。原PDF与整页渲染留在 `参考资料/`。该图是1982年的历史布置资料，用于核对基本关系，不宣称为2026年实测布局。来源未显示可再分发许可；原页仅作研究参考，不直接用作公开视频画面。

N1-02、N1-03、N1-05生图调用显式传入上述整页图作为结构参考；N1-01、N1-04只表达山地向平原过渡与重力引水的概念。

机制交叉核对：[国家民委刊载的李钊访谈](https://www.neac.gov.cn/seac/c103391/202308/1166522.shtml)、[阳泉市水利局《都江堰水利工程》](https://slj.yq.gov.cn/12684/202304/t20230411_1568165.html)。鱼嘴分内外江，飞沙堰将多余水沙溢向外江，宝瓶口为通往灌区的狭窄进水口。原N1-05中的“循环”不表示水流回到上游。

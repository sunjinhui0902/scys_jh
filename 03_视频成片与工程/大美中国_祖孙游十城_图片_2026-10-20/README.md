# 《大美中国》祖孙游十城：上下集图片包

制作日期：2026-10-20。22张独立AI场景图＋3张用户提供的书本主素材，另保留1张备用商品图及5张上集城市图副本供下集快闪。

## 直接使用

- `ep1_assets/`：上集11张，`ep1_01.png`～`ep1_11.png`。
- `ep2_assets/`：下集11张，`ep2_01.png`～`ep2_11.png`。
- `book_assets/`：上下集共用3张，按用户追加要求保留原始尺寸和文件内容，不缩放、不补边、不重绘文字。
- `ep2_reuse/`：下集结尾快闪5张副本，与上集源文件SHA-256相同。建议顺序为平遥→延安→开封→苏州→杭州。
- `contact_sheet.jpg`：26张唯一素材总览，含1张备用商品图；上面的编号只用于选图，不属于视频画面。
- `大美中国_上下集图片包.zip`：上述交付图、备用图、快闪副本及说明、提示词、校验清单。生成原图另存 `originals_ai/`。

22张AI图使用内置 `image_gen` 逐张生成，采用统一祖孙衣着、摄影质感和竖屏构图；导出时仅进行尺寸规范化至1080×1920（9:16），非原生8K。完整提示词与两次定向修订提示词保存在 `prompts.json`。保留模型原生文件以供追溯。

## 剪辑说明与使用边界

1. 新建1080×1920竖屏工程，上集、下集按各自编号导入；两集复用 `book_assets/`。
2. AI图本体不添加标题字幕；后期结合画面在上、下区域排字，先检查人物手部与主体是否被遮挡。15%是构图目标，不是全画幅均为纯色空白的保证。
3. 下集快闪使用 `ep2_reuse/` 中按01～05排序的文件，每张建议0.3～0.5秒，节奏以实际配音为准。
4. 书图按原尺寸交付，在剪辑软件中等比适配并补工程背景，避免裁掉封面文字和内页。
5. 22张均为AI生成的旅行氛围画面，建筑细节、佛像形制、河道布局和场景组合未按现场照片逐项核验，不能作为文物或水利结构证据。配音涉及精确细节时应搭配真实资料图。成片显著标识AI画面。
6. 成都茶馆表演为叙事氛围组合，不证明特定茶馆、日期真实有该演出；家庭伴读书页为虚构无字风景图册，不是《大美中国》的真实内页。商品封面与内页展示请用 `book_assets/`。
7. 本包保留用户拟定的十城顺序和主题；不证明存在官方“十大历史名城”排名，也未完成挂售版本、素材权利和发布审核。

本次交付范围为图片制作与整理，不含成片、配音、字幕工程或发布。

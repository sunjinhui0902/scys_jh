## 🚀 极速视频生产黄金管线闭环

当你想制作一条新视频时，只需执行以下极简三步走：

```mermaid
sequenceDiagram
    autonumber
    actor User as 创作者 (用户)
    participant Ref as 本规范库 (final_scys_reference)
    participant Gemini as 网页 Gemini
    participant Agent as Antigravity (开发环境)
    participant GPT as GPT (生图)
    participant JianYing as 剪映电脑端

    User->>Ref: 1. 挑选心仪题材的钩子与转折模板 (如 H01 + B01)
    User->>Gemini: 2. 粘贴 06 卡中的提示词宏，输入选题与目标图书
    Gemini-->>User: 3. 输出去AI化短句口播 + 6-8 张 GPT 分镜 Prompt
    User->>Agent: 4. 提供口播文案，启动初始化
    User->>GPT: 并行提供 Prompt 生成图片素材
    Agent->>JianYing: 自动装配配音、中老年字幕、国风BGM、占位图 (15秒内草稿就绪)
    GPT-->>User: 图片生成完毕 (约15~20分钟)
    User->>Agent: 将图片放入 02_分镜视觉素材/ 并执行热替换
    Agent->>JianYing: 3秒秒级替换草稿图片路径，保留关键帧运镜与转场
    JianYing-->>User: 最终成片完美就绪，直接导出！
```

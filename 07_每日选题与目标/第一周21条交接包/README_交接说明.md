# 第一周 21 条交接说明｜给 Gemini / GPT / Antigravity 的分工与指令

## 先说最重要的变化

这批稿和以前不一样：**口播已经定稿冻结，Gemini 不许再写文案、不许改一个字。**
以前播放量差，一个重要原因就是文案在 Gemini 那里反复加工，出现过编造社证（假装有人催更）、同稿数字自相矛盾这类问题。这次分工改成：

| 角色 | 这次只干什么 | 绝对不干什么 |
|---|---|---|
| 你（xun） | 把交接包逐条喂下去、验收、排期发布、回填数据 | — |
| Gemini | 把分镜扩写成 GPT 生图 Prompt 清单 + 切屏显短句 | 不改口播、不新增台词、不换选题 |
| GPT | 按 Prompt 逐镜生图 | 不生书本镜头（书图用实拍） |
| Antigravity/Codex | 跑 fast_draft_pipeline 装配剪映草稿、生图后热替换 | 不动音色/BGM 默认基准、不改字幕文案 |

交接包位置：`第一周21条交接包/`，21 个文件夹，一个视频一个，命名 = 编号_日期_时间（如 `W1_11-03_1900`）。每个文件夹里有：
- `口播.txt`：纯净口播，直接喂管线配音用
- `制作卡.md`：封面大字、发布标题、分镜、置顶评论、待核事项，全在里面

交接节奏：**一条一条交，不要把 21 条一股脑塞进同一个 Gemini 会话**，会串稿。生产顺序按日期：先做 11-03、11-04 的 6 条保排期。

## 一、给 Gemini 的指令（每条视频复制一次，把制作卡全文粘在指令后面）

```
你是分镜与生图提示词助理。下面是一条已定稿的视频号口播（冻结版），你的任务只有两个：


1. 口播一字不改：不润色、不删减、不新增、不调换顺序。发现疑似事实问题，只在最后的「疑问清单」里列出，不许自行修改。
2. 按制作卡的分镜表逐镜输出 GPT 生图 Prompt，镜头ID 用「编号-镜号」，如 W1-01、W1-02。
3. 每条 Prompt 必须包含：画面主体、构图、光线、风格（写实纪实摄影感、暖色自然光）、画幅 9:16 竖版。
4. 人物只出现背影、侧影或手部特写，禁止正脸；画面内禁止出现任何文字、字幕、水印、logo。
5. 分镜里标注「示意图」的镜头，Prompt 写明“简洁手绘地图/剖面示意图风格”，并预留角落位置给后期加「示意图」标注。
6. 最后一镜（书本/日历实拍）不生成图片，Prompt 一栏只写「实拍占位」。
7. 屏显短句：把口播原文切成 5-9 个汉字的短句序列，只切分、标点可去掉，字一个不许改。


## 生图Prompt清单
- W1-01｜<Prompt全文>
- W1-02｜<Prompt全文>
……
## 屏显短句
<逐行输出切分后的短句>
## 疑问清单
<没有就写“无”>

以下是制作卡全文：
<把对应文件夹里的 制作卡.md 全文粘在这里>
```

验收标准：拿 Gemini 输出的屏显短句和 `口播.txt` 对一遍，字对不上就打回重做，这一步不能省。

## 二、给 GPT 生图的交接（沿用仓库批量出图标准）

1. 按镜头ID逐条提交 Prompt，**原样提交，不额外附加全局人物设定**（仓库既有规定）。
2. 出图文件直接命名为镜头ID，如 `W1-01.png`，放进该视频工程的 `02_分镜视觉素材/`。
3. 默认 3 个请求在途、最多 4 个（仓库滑动调度口径），完成一张补一张。
4. 哪张不合格只重哪张，不要整批重跑。
5. 书本/日历镜头跳过不生图，用实拍图按原尺寸放入（仓库既有规定）。

## 三、给 Antigravity / Codex 的工程交接

1. 工程目录沿用仓库结构：`03_视频成片与工程/<编号_日期_时间>/`，把交接包对应文件夹的 `口播.txt` 作为管线输入。
2. 阶段一与生图并行，立即执行（不要等图）：
`python scripts/fast_draft_pipeline.py init --dir "03_视频成片与工程/<编号_日期_时间>"`
草稿就绪后马上提醒 xun：草稿已好，等 GPT 生图放进 `02_分镜视觉素材/`。
3. 生图到齐后执行热替换：
`python scripts/fast_draft_pipeline.py apply-images --dir "03_视频成片与工程/<编号_日期_时间>"`
4. 音画基准不动：解说音色 zh-CN-YunjianNeural、语速 -8%、音调 -6Hz；BGM 用食力过日子国风版，音量 -12 至 -14 dB，人声 +2.5 至 +3.5 dB。
5. 每条装配完回报三个数：实际时长、字幕条数、缺图镜头ID。时长超过 78 秒的，先按下面「超时备删句」删句重跑配音，不许自行改写其他句子。

**超时备删句（只有超时才删，删后语义不受影响）**

# S01｜V2 视觉返工要求

## 结论

现有 80 秒样片只保留为技术样机。7 张底图都采用深色工程汇报卡样式，信息密度太高；首帧有多个说明框、列表和内部声明，城市图形还出现缺字方框。观众需要看的水窗动作反而不突出。V2 需重做画面语言，不能仅换颜色、字体或背景图。

## 视觉方向

- 采用「文旅纪录片插画 + 简洁二维动态剖面」：古城和雨水用有质感的插画表现，水窗开合用清楚的平面动画解释。插画标明“原理示意”，不冒充赣州实景或古建复原。
- 统一为墨蓝、石灰白、暖砂金三色；雨水和排水箭头用一种亮青色。不要霓虹边框、表格、代码式面板、卡片堆叠、表情符号和装饰性进度条。
- 每个镜头只让观众看一个主体、一个动作。安全区内除口播字幕外，最多保留一个地点/动作标签；不放段落、列表、论文式标题。
- 字幕置于画面下部，保持 5～9 字短句，使用能完整显示中文的字体；逐帧检查方框缺字、遮挡和小屏可读性。
- 内部事实、授权、商品待核与验收说明放进交付文档，不进入观众画面。画面需要说明性质时，只用角落小字“原理示意”。

## 镜头改法（先做视觉样张，时长可随口播调整）

| 时间 | 观众看到的主体与动作 | 画面文字 |
|---|---|---|
| 0～6 秒 | 暴雨落在非特定古城轮廓，城内积水向墙边流；镜头切到城外江水水位上升，形成冲突。不要用整页问题分析图。 | 只显示当句字幕 |
| 6～16 秒 | 简化的古城与两江位置图，从俯视转入地下排水路径。地图只能表达已核实的位置关系，不能加未经核实的精确高程。 | 必要时标“章江／贡江” |
| 16～30 秒 | 一股雨水沿沟渠进入池塘，水位缓慢上升；以动态水流代替沟塘文字清单。 | 只显示当句字幕 |
| 30～45 秒 | 放大一个出水口剖面：城内水位较高，水流向江侧排出，水窗开启。镜头中只留水位线、门板和一根方向箭头。具体转轴、角度及构造无来源时不画。 | “向外排水” |
| 45～60 秒 | 保持同一构图，江水水位升高，流向反转，水窗闭合；通过前后状态切换让人一眼看懂。不要写“彻底断绝”“永不倒灌”。 | “阻挡倒灌” |
| 60～70 秒 | 镜头拉远，沟渠、池塘、水窗三个要素依次亮起，形成系统关系；不做三栏总结卡。 | 只显示当句字幕 |
| 70～80 秒 | 若具体商品版本和目录仍未核实，使用古城与水路的干净收尾画面，不展示虚拟书封、书名卡或“未挂载”说明。核实后再另做商品版结尾。 | 一句自然收束语 |

## 交付顺序与验收门槛

1. **先交 3 张无内部说明的竖屏关键画面**：开头暴雨（约 2 秒）、水窗向外排水（约 38 秒）、水窗闭合（约 52 秒）。附一张手机实际显示尺寸的预览图。先审视觉，不先渲染整条。
2. 关键画面通过后，做 10～15 秒动画小样，检查水流方向、水位变化、字幕与画面节奏，再做完整 60～90 秒样片。
3. 核对事实后才能沿用原口播。尤其删除旧分镜中的“落差 10～20 米”、没有出处的转轴与开合角度，以及缺证据的历史引句。
4. 保留 V1 文件，V2 单独建目录；不要运行旧的固定目录成片脚本，不覆盖原样片或剪映草稿。记录每一步真实制作时间，以便评估每天 3～5 条的可行性。

## 一眼判退标准

- 任一画面出现超过两个非字幕文字区块；
- 画面主体被文字框遮住，或看不出水往哪边流；
- 有方框缺字、内部验收文字、权利声明或未经核实的商品暗示；
- 换了配色但仍是 7 张静态汇报卡。

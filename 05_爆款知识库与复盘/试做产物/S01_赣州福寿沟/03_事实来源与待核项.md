## 重点核对：水窗开合方向与水力动力学原理

水窗是福寿沟系统最关键的控制节点，位于城墙地下排水分渠通往章江、贡江的出水外墙处。本次打磨对水窗的开合方向、受力条件与协同机制进行了严格核对与工程还原：

```
                【水窗断面启闭动力学示意】

   城内福寿沟 (暗渠)          宋城墙出水口         城外江面 (章江/贡江)
   ──────────────────┐          ┌──────┐          ┌──────────────────
                     │          │ 顶轴 │● (铰链)  │
   [城内积水]       ===▶ 水流   │      │\        │  [江水水位低]
   (水位高·水压大)   ===▶ 冲开   │      │ \木闸门  │
   ──────────────────┘          └──────┘  ▼ 向外开└──────────────────
                                           (排水入江)

   ──────────────────┐          ┌──────┐          ┌──────────────────
                     │          │ 顶轴 │● (铰链)  │  [江水暴涨！]
   [内水暂存入塘]    │ 阻止倒灌 │      ││ 紧压窗框│◀=== (水位高·水压大)
   (水窗后水位低)    │ ◀─────── │      ││ [死死闭合]◀=== 反向推力
   ──────────────────┘          └──────┘└─────────┴──────────────────
```

### 1. 排水开启方向：向城外（江面）推开
- **结构特征**：水窗由条石窗框与木质闸板构成。木闸顶端设有活动转轴（铰链），闸板受重力自然垂直悬挂在出水口外侧窗框槽内。
- **开启动力**：当城内下暴雨、地下福寿沟积水水位**高于**城外江面水位时，城内沟道产生由内向外的静水压强与动水推力。
- **动作过程**：水流从暗渠喷涌而出，正向水推力克服木闸自身重力，将闸门**向外（向江面方向）顶开一个角度**（约30°～45°），城内雨水畅通排泄入江。

### 2. 防倒灌闭合方向：反向紧贴外侧窗框死死闭合
- **受力条件**：当外部江河遭遇汛期洪峰，章江、贡江水位暴涨，江面水位**高过**城墙出水窗口。
- **动作过程**：江水试图顺着排水口倒灌入城，产生巨大的由外向内的反向水动力。此时江水反向推力将悬挂的木闸门**死死推贴在条石窗框的外边缘凹槽止水面上**。
- **闭合效果**：外江水位越高、水压越大，水窗被反向压得越死越紧，形成天然自闭密封，彻底断绝江水倒灌城内的通道。
- **自动化价值**：全过程纯靠水力压差自主工作，无需任何人力值守开闭，亦无电力机械故障风险。

### 3. 闭窗期间城内雨水的“沟塘调蓄”接力
- **关键逻辑**：水窗闭合后，如果城内仍在大雨，城内积水如何处置？
- **协同机制**：福寿沟并非封闭管道，而是与赣州城内数十处天然低洼水塘（如凤凰池、清水塘、金鱼池等）互联互通。
- **调蓄过程**：外江顶托导致水窗闭合期间，雨水沿福寿沟倒流充盈入城内池塘暂存（类似现代海绵城市的调蓄下沉广场）；待外江洪峰退去、江面水位低于内塘水位后，水窗在内水水压下再次自动冲开，池塘暂存积水错峰排入江中。

## 事实核验与竞品神话纠偏项（严禁使用虚假夸大）

| 竞品原台词／网络常见误传 | 事实核验结论 | 本片处理与纠偏措施 |
|:---|:---|:---|
| **“最绝的是他九百多年没被淹过”**<br>“赣州从不内涝，人称不落浮城” | ❌ **严重不符历史与现代防汛事实**。<br>历史上赣州遭遇超特大洪水（如江面暴涨翻越城墙垛口、或连续极端特大暴雨导致城内池塘完全满溢）时，低洼城区曾多次出现积水内涝记录（包括1998年特大洪灾等水文记录）。 | **坚决删除“从不内涝”、“绝不进水”等绝对表述**。<br>在第 28 句明确口播：“这不是从不内涝，是因地制宜智慧”，引导受众客观认识古代水利工程的科学价值与客观物理极限。 |
| **“水窗是神仙设计，任何洪水都挡得住”** | ❌ **不科学**。水窗是单向阀拍门原理，只能阻挡出水口高度以下的江水倒灌；一旦江水高过防洪城墙顶部，水窗无法阻止漫堤。 | 严谨定性为“重力自流、水力自启闭、沟塘错峰调蓄”的古典水利工程体系。 |
| **“刘彝修了十二点六公里福寿沟，像古篆体福寿二字”** | ⚠ **民间附会修辞**。文保测绘证实福寿沟依古城南高北低天然冲沟走向顺势开挖，并非工匠刻意在地底画字。 | 口播中保留“福沟”排贡江、“寿沟”排章江的分区事实，不宣扬篆字迷信传说。 |

# S04｜分镜与视觉设计（剪映多轨道动态运镜与实景/意境融合）

## 一、 视觉生产原则与风格升级

根据最新纠偏指令与《说书式口播写法》要求，本工程彻底升级为**剪映多轨道动态运镜工程**：
1. **多镜头切片动态叙事**：严禁全片 3 张死图轮换，全片按 7 个叙事段落解构成 **13 个镜头切片**（平均镜头时长 5~8 秒，节奏舒缓富有呼吸感）；
2. **剪映原生动态运镜（消除 PPT 感）**：为每个静态画面注入剪映原生运动关键帧（`Scale 1.00 -> 1.15` 慢推推进、`Scale 1.14 -> 1.02` 宽广拉远、`Pan X` 横移巡览、`Tilt Y` 仰角俯仰），画面保持持续微动；
3. **真实摄影与实景古迹优先**：
   - 核心古都遗址（二里头遗址现场）、地标（应天门日夜景实拍、定鼎门遗址博物馆）、文物（河南博物院隋唐都城沙盘）优先采用公开授权的高清实拍；
   - 概念示意仅用于宏观河洛山川空间关系，严禁使用任何生硬的“概念插画·非实景”工程框遮挡画面；
4. **原生大字律动排版**：字幕作为剪映原生文本轨导入，字号 12.5（中老年友好大字）、纯白字身、黑色粗描边（`width=40.0`）、安全下沉 `transform_y = -0.68`，避开视频号右侧点赞栏与左下角带货橱窗；
5. **典藏书卷留白合规**：尾页书籍画面以茶台大书内页与经典烫金封面呈现，绝不伪造未经授权的实体封面或编造未核实内页，实事求是引向目录篇章。

# 三条原创口播与分镜｜试读稿

2026-10-15。根据参考书线索独立创作，核心事实另经官方资料交叉核验。目标为约60～90秒；未实际试读、配音或校时，镜头按叙事段落分配，录音后调整。画面是待拍或待取得的素材需求，不表示已经有可用素材。

## 01｜平遥：走过城墙之后，看看生意留下了什么

### 完整口播

去平遥，你会先拍城墙，还是先逛老街？

我想给你换个看法：进城以后，先找一家老票号。

平遥的故事，有一部分就藏在这些做生意的地方。十九世纪到二十世纪初，它曾是中国重要的金融中心。街巷、店铺、院落，也留下了那段商业历史的痕迹。

再看日升昌票号旧址，你可以带着一个问题：过去没有手机转账，远处的一笔生意，要怎样把钱往来办成？

先别急着记答案。带着这个问题走一圈，眼前的门面和院落，也许就比一张古风照片多了一层意思。

想接着读，可以从《小城大历史·北方篇》的平遥条目开始。把城墙、票号和寺院分别找出来，下次去，你就能自己选一条想了解的线索。

### 镜头草案

| 段落 | 画面动作 | 屏幕短字 |
| --- | --- | --- |
| 设问 | 城墙远景切入老街，避免整段空镜 | 先看哪一面？ |
| 转向 | 票号旧址外部、可识别的场所标识 | 找一家老票号 |
| 核心事实 | 街巷、铺面、院落依次切换 | 城市里的商业史 |
| 留问题 | 经授权拍摄的票号相关展陈，不伪造具体汇兑单 | 钱怎样到远方？ |
| 观察 | 回到同一处门面或院落 | 带着问题看 |
| 参考阅读 | 自有实体书实拍，打开已核的平遥条目 | 从平遥读起 |

事实台账：城市金融角色与时间段见[UNESCO平遥古城](https://whc.unesco.org/en/list/812/)；票号及日升昌旧址线索见B03 PDF 42–43、B01 PDF 100。参考阅读确有对应条目，不意味着已经核对实际带货SKU。没有写“第一家银行”、具体票号业务流程、今日展陈内容和全城金融占比。

## 02｜大同：为什么看石窟，还要想到北魏？

### 完整口播

站到大同云冈石窟前，你会先看什么？佛像的大小，还是那张脸？

下次可以多带一个问题：这些石头，为什么会在这里留下这样的模样？

云冈石窟的重要营造发生在五到六世纪，背后连着北魏的历史。它的艺术也汇合了来自南亚、中亚的影响，与中国的文化传统相结合。

所以看石窟，可以慢一点。先看人物，再看衣纹和周围的雕刻。遇到不同的造型，先把疑问留下：它用了怎样的表达，又让你想起了什么？

一面石壁，也可以成为认识一段历史的入口。

想先读点背景，就翻《小城大历史·北方篇》的大同条目。从城市读到云冈，再回来看石头上的细节，问题就有地方接着找了。

### 镜头草案

| 段落 | 画面动作 | 屏幕短字 |
| --- | --- | --- |
| 设问 | 云冈实景全貌后切真实造像，地点对应 | 你先看到了什么？ |
| 核心问题 | 同一造像由近到远 | 为什么在这里？ |
| 背景 | 简洁的“五至六世纪／北魏”时间提示 | 石窟与北魏 |
| 交流 | 用真实细节展示，配简明概念箭头；不编造具体传播路线 | 不同文化的相遇 |
| 观察 | 衣纹、人物、周围雕刻；不随意标定未经核验的风格归属 | 先观察，再追问 |
| 参考阅读 | 对应实体书的大同条目 | 从大同读到云冈 |

事实台账：营造时代与文化交融见[UNESCO云冈石窟](https://whc.unesco.org/en/list/1039/)；B03 PDF 40–42有大同、云冈内容。不采用不同口径的洞窟数量，不把AI示意图当作真实古迹细节，不按未经确认的具体造像解释服饰来源。

## 03｜苏州：园子不必很大，为什么还值得慢慢走？

### 完整口播

逛苏州园林，你会不会进门先找那张最出片的角度？

下次不妨换个玩法：先站定，再沿着廊子走几步，看看眼前的画面有没有变化。

苏州古典园林有一种有意思的本领：在有限的空间里，用水、石、植物和建筑，营造出山水的意味。

所以你不用急着把全景拍完。找一处门洞，看它让你注意到了什么；再换一个位置，比较刚才看见的东西。这里说的是一种观察方法，不是每座园子都要套同一道题。

风景有时不只在远处，也在你换了位置以后。

如果想带着背景再去看，可以读《小城大历史·南方篇》的苏州条目。先认出几个园名，再选一处慢慢逛，看看你会留下什么问题。

### 镜头草案

| 段落 | 画面动作 | 屏幕短字 |
| --- | --- | --- |
| 设问 | 真实园林入口或园内景观 | 不急着找机位 |
| 体验 | 同一场景固定机位与移动视角对照 | 换个位置看 |
| 核心知识 | 水、山石、植物、廊亭各一镜 | 小空间里的山水 |
| 实践 | 真实门洞前后两处站位，保持空间关系准确 | 这次看见了什么？ |
| 回看 | 重现第一镜，对照观众的新观察 | 留一个问题 |
| 参考阅读 | 对应实体书苏州条目 | 从苏州条目读起 |

事实台账：小空间模拟自然、园林组成元素见[UNESCO苏州古典园林](https://whc.unesco.org/en/list/813/)；B02 PDF 29–30确有苏州及园林介绍。口播中的移动观察是本次原创建议，不冒称书中固定游线。不说四大名园的全部现存建筑分别完整建于宋元明清。

## 三稿怎么用于带货

当前结尾准确指向参考书。若实际在售的是另一本书，保留前面的城市故事，依据实际商品目录和内页证据重写引书段。不能直接换书名并保留“书中详解了这一古迹”的承诺。

下一次只需先试读一条，记录真实时长，调整停顿和名词密度，然后配画面。3稿尚未形成已发布或已验证转化的成品。

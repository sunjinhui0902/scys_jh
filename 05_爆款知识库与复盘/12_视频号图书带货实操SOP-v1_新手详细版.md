# 视频号图书带货实操 SOP-v1｜新手详细版

修订日期：2026-10-16。适用对象：第一次从选书做到视频发布、需要逐项操作说明的人。状态：操作教学稿，待用户首轮实际执行后修订。

**这一版要帮助你完成一件具体的事：选定一个方向、筛出一本实际商品、做出第一条原创视频，再按同样的方法完成首轮小批测试。**先照顺序做，做到哪一步就填哪一张记录，不需要一次学会所有工具。

## 怎么使用这份手册

第一次操作按第0～14步走。第6步确定形式后，首次可选单人讲解；金句和双人播客、动态书单的完整操作另放在附录A～C，不必同时学习三种。第7～12步以电脑剪映为例，手机负责查看账号、核对商品和最终预览。

各步都说明：要做什么、从哪里进入、逐项动作、填写示例、常见卡点和完成检查。文中的“课程参考入口”来自课程文字，**未登录你的微信和剪映逐按钮实测**；入口名称、额度、收费、权限以你当时的正式界面为准。找不到时按该步的替代办法走，不必反复寻找同名按钮。

### 课程方法与本版补充

基础来源为[生财课程156](https://scys.com/course/detail/156?chapterId=9853)。本次通过MCP读完以下8节文字：项目逻辑9848、前期准备9852、定赛道与选品9853、口播9856、金句9857、动态书单9858、发布9861、复盘9862。课程图片和演示视频未逐项观看，不将下面的文字步骤冒充逐屏截图复刻。

本版保留课程的“账号准备—找需求—定赛道—选品—写稿—配音配图—剪辑—发布—复盘”主线，补充了原创教学案例、提示词、文件命名、失败处理和完成检查。小批数量、时间安排、导出起始参数是本版练习设计，不是课程或平台的统一要求。

原课程有中长视频、多个账号和不同发布频率的经验。本项目当前文史短片先按[内容执行标准](09_带货内容执行标准.md)做60～85秒目标时长；若以后选择3～5分钟讲解，增加证据和内容深度，再按实际配音重新分镜，不能把短稿机械拖长。

### 先认识8个词

| 词 | 新手可以这样理解 |
| --- | --- |
| 赛道 | 持续给同一类人讲同一类问题，例如古建筑的观察方法 |
| 对标 | 观察别人如何满足需求，学习问题选择和表达方法 |
| 选品 | 选定实际要挂售的商品，落实到版本、店铺和商品链接 |
| 橱窗 | 账号展示商品的页面；是否可用按账号实际情况确认 |
| 挂车 | 把一件商品关联到具体作品，观众可从作品进入商品 |
| SKU | 商品的具体规格编号，例如同书不同套装、精装版与平装版 |
| 佣金 | 按实际交易规则结算给你的推广收入，尚未扣除你的全部成本 |
| 完播/留存 | 看完的人占比，或看到某个时间位置的人占比；以后台定义为准 |

## 第0步：准备工具和一套不会弄乱的文件

**要做什么：**保证资料、音频、图片和最终视频找得到，先跑通一条作品。

### 0.1 准备最小工具组合

| 工具 | 用来做什么 | 首次怎么处理 |
| --- | --- | --- |
| 本人正常使用的微信与视频号 | 找内容、查看后台、发布 | 先检查现有账号，不为练习额外买手机或电话卡 |
| 一个能够上传文字/图片的AI助手 | 整理资料、提问题、写原创稿 | 先沿用已有工具，不同时切换四五个助手 |
| 剪映 | 导入素材、配音、字幕、导出 | 从[官方入口](https://www.capcut.cn/)安装或更新，不先购买会员 |
| 生图工具（可选） | 制作氛围图或概念插画 | [即梦官网](https://jimeng.jianying.com/)可作入口；具体模型与收费看当前页面 |
| 文本或表格记录工具 | 记选书、事实、发布数据 | 直接使用文末记录模板即可 |

即梦官网当前公开说明含文/图生图、文/图生视频和智能画布能力；这只确认产品能力类别，不代表本账号拥有某项额度或套餐。先用已有照片、合法商品资料或一张简单底图也能练剪辑。

### 0.2 建立当期文件夹

在自己的工作目录新建“练习01_具体题目”，里面建以下子文件夹；不要把素材散在桌面和微信下载目录。

```text
练习01_具体题目/
  01_商品与资料/     商品信息、目录、事实卡
  02_文案/           选题、口播_v01、口播_v02
  03_声音/           试听、最终配音
  04_画面/           镜头01、镜头02等
  05_剪辑与导出/     草稿说明、预览版、最终版
  06_发布与复盘/     发布记录、24小时与72小时快照
```

在本项目中，需要制作时放入`03_视频成片与工程/`下的独立工程；本次仅交付手册，没有新建视频工程。采集原视频不纳入恢复包；无需为了这份练习下载同行整条视频。

### 0.3 起一个作品编号

例如`T01_古建入门_屋顶观察`。同一条稿的修改用`v01、v02`；换题目用`T02`。剪映草稿名、音频名和复盘编号保持对应，避免把旧配音放进新文案。

**卡住怎么办：**工具提示付费时，先看能否用免费功能完成。文字朗读不可用，就录自己的声音；生图不可用，就用可用且许可清楚的画面。不要在第一条作品前购买一堆软件。

**完成检查：**你能找到当期文件夹、作品编号、一个AI助手和一个可用剪辑工具。

## 第1步：检查账号、完成基础资料

来源：[前期准备9852](https://scys.com/course/detail/156?chapterId=9852)。

### 1.1 找到自己的视频号

1. 手机打开微信，在“发现”里进入“视频号”。
2. 找右上角的人像、个人中心或“我”，进入自己的账号页面。
3. 已有视频号就查看现状；没有才按页面提示创建。注册信息、协议和实名由账号本人按正式流程处理。
4. 记下账号名、是否能正常发布、后台是否有明确违规或功能限制。
5. 不用通过零钱、加陌生人、虚假聊天来“模拟真人养号”。先正常使用本人账号，把内容做清楚。

### 1.2 先定内容承诺，再改名字和简介

1. 暂定一个读者需求，例如“让第一次看古建的人知道观察什么”。
2. 为名字准备3个候选，尽量短、好读、能看出内容方向。
3. 头像先用自己有权使用的简单图形或原创文字标识，缩小到手机头像大小检查是否能辨认。
4. 简介写“讲什么、给谁看、能获得什么”。有真实购买路径后再补购买说明。
5. 从主页的“设置/资料设置/编辑资料”入口修改；具体标签可能不同。保存后退出再进一次，确认修改成功。

**教学示例（未核查昵称是否可注册）：**

- 名字候选：古建慢慢看、带着问题逛古城、城里有门道。
- 简介示例：每次讲清一个古建细节。带你从看热闹，到知道看哪里。

这只是账号文案示范，不声称任何专业资质或机构关联。不要因为课程提过某个昵称修改次数，就反复试改；按当前界面提示处理。

### 1.3 查“橱窗”和“作品挂商品”分别是否可用

1. 参考入口：视频号个人页→创作者中心→带货中心或商品相关页面。
2. 查看当前账号可用的功能和申请条件；把“商品展示/橱窗”和“短视频关联商品”分开记录。
3. 如需实名、资料、保证金或其他条件，记录当前页面要求。不要沿用课程里的固定粉丝数和金额。
4. 条件没满足，就把作品状态写为“可做内容练习，购买路径待开通”，继续选题和制作。

**完成检查：**填写账号卡：`账号名｜可正常发布？｜橱窗可用？｜作品挂商品可用？｜尚缺条件｜核对日期`。不要求此时所有带货权限都已开通。

## 第2步：确定读者问题和一个细分赛道

来源：[定赛道与选品9853](https://scys.com/course/detail/156?chapterId=9853)。

### 2.1 从四类方向理解“卖书帮人解决什么”

| 课程涉及的方向 | 可以进一步缩小成什么问题 | 要准备的内容能力 |
| --- | --- | --- |
| 政史社科 | 怎样看懂一座古城、一段制度或一个人物选择 | 可靠史料、时地关系、避免把猜测当事实 |
| 商业经管 | 初次带团队如何反馈、普通人如何理解一种商业模式 | 有出处的案例，区分作者观点和普遍结论 |
| 家庭教育/科普 | 亲子共读怎么提问、一个自然现象怎么解释 | 对应年龄和场景，不保证教育效果 |
| 健康生活 | 如何阅读食品标签、如何理解基础健康概念 | 更强事实核对；不能把生活知识包装成诊疗方案 |

这些是课程方向的应用举例，不是本次验证过的赚钱排行榜。第一轮选自己能核对、能讲明白的一类即可。

### 2.2 写一张定位卡

1. 有后台人群数据就记录其统计周期；没有数据就写“假设受众”。
2. 想一个具体使用场景：周末出游、亲子阅读、通勤听书等。
3. 写出对方的问题，避免只写“想涨知识”。例如“到了古建筑面前，不知道先看哪里”。
4. 写出一次视频能兑现的小收获。例如“学会从三个位置开始观察”。
5. 写出图书能继续提供什么：系统图示、主题索引、可重复查阅的说明等；具体卖点留待选书后核验。

**教学填写：**`假设受众：对古建有兴趣但缺乏入门方法的旅行者；场景：出发前做功课；问题：记不住构件名称，也不知道看哪里；视频收获：拿到一个观察顺序；图书需求：有图有解释、可以带着问题查阅。`

### 2.3 检查方向是否过大

“历史文化”太大→缩成“旅行时看懂古建”→首轮再缩成“一个看得见的细节怎么观察”。先列10个候选问题，不要求马上回答全部；资料不足的题先搁置。

**卡住怎么办：**一个问题也想不出，先去第3步观察评论；不要靠AI随意编10个“惊天秘密”。暂时找不到能卖的书也正常，下一步验证商品供给。

**完成检查：**能说清“给谁、在什么场景、解决什么问题”；暂定一个方向，且标出受众是数据支持还是假设。

## 第3步：手动找10条对标，学会看什么

### 3.1 搜索，不只靠首页推荐

1. 进入视频号搜索。围绕定位列3～5组词：如“古建筑入门、古城旅行、屋顶怎么看、古建图书、园林怎么逛”。
2. 每组词先看几条内容，筛掉明显无关的。
3. 先收集10条、覆盖至少3个账号。兼顾不同体量，不只选一个大号。
4. 优先留意近期发布和持续更新的作品，同时保留具体日期；若平台没有日期筛选，就手动记。
5. 保存可正常打开的链接或平台内收藏位置。只记录所需信息，无需下载整条视频。

### 3.2 一条作品按“四看一记”观察

1. **看开头：**它先提出了什么问题？是具体物件、生活场景，还是一句空泛的大道理？
2. **看解释：**它用故事、比较、步骤还是图示讲清楚？自己能否补出独立的新角度？
3. **看画面：**真人、静图、结构图、书页各承担什么作用？你是否有相应素材条件？
4. **看引书：**商品与前面问题是否相符？书名、版本和购买入口有没有真的对应？
5. **记真实提问：**评论里有人问“哪里能看到、具体怎么做、书里有没有图”时，摘记问题即可，不收集私人联系方式。

可见点赞、评论、收藏、粉丝数都记上，并写采集时间。看不到播放或成交就留空，不从爱心数反推销量。

### 3.3 怎样判断哪条值得继续研究

值得留：和目标需求一致、问题具体、评论确有相关疑问、你能取得资料并做出独立解释。

暂缓：高互动主要来自争吵、依赖你拿不到的稀有素材、需要模仿名人才能成立、或商品与内容无关。

**教学观察记录（全为假设）：**`作品A：提出“逛古建为什么只会拍门头”；评论有人问“有没有入门图解”；可学的是“把旅行困惑变成一个可操作问题”；不复制它的文案、画面和声音。`

### 3.4 让AI帮你归类，但不要让它补造数据

把10条记录粘给AI，输入：

```text
根据下面的真实观察记录，按“观众问题”归成3～5组。
每组列：对应记录编号、反复出现的问题、我能原创补充的角度、缺少的证据。
不能把点赞当销量，也不能猜看不到的播放、成交或粉丝数。
最后提出3个值得小批测试的问题，并说明选择依据。
【在这里粘贴观察记录】
```

**卡住怎么办：**搜索结果很少就把词放宽，例如从具体构件名改成“古建筑入门”；如果只有景点打卡而没有图书需求，照实记录，别硬判定已有购买意愿。

**完成检查：**有10条可回看的记录，并能提炼3个有依据的候选问题。

## 第4步：找到10本实际商品，分清书名和版本

### 4.1 先用官方选品入口

1. 手机参考入口：视频号个人页→创作者中心→带货中心→选品或商品相关入口。
2. 电脑可从[微信小店带货助手](https://store.weixin.qq.com/talent/home?from=platform)进入；需要登录时由本人完成。
3. 搜书名或类目词；有价格、佣金筛选就使用，没有就逐项打开比较。
4. 看到候选书先打开详情，核对是不是你想要的那一本、那一版。
5. 复制可用商品链接或记录商品ID、店铺和规格；不要只截封面就退出。

课程把50～200元、30%以上佣金等作为不同层次的初筛参考，本版不强行叠成门槛。先按需求搜，再比较内容和单笔收益。

### 4.2 每本先填这几个字段

`候选号｜书名｜出版社/作者｜版次或ISBN｜平装/精装/套装｜店铺｜链接或SKU｜价格与采集时间｜佣金条件｜目录样页位置｜暂定用途`

ISBN可在详情或版权页找。ISBN用于核对书的版本；店铺商品ID用于核对具体售卖链接，两者不能互相替代。赠品、册数和装帧不同也要单独注明。

### 4.3 再用其他来源补候选

- 同行商品：查看其真实商品页，自己核对目录、版本和服务，不把对方卖点直接复制过来。
- 其他平台榜单：找到候选书，再回到视频号官方商品页查；外站热销不能证明本账号能卖。
- 出版社官方号或旗舰店：找目录、样页、样书政策和素材许可说明。首次可以只查公开资料。

### 4.4 要问商家时，先准备清楚的问题

下面是你可以自行发送的询问信息，本次不会代你发送：

> 我在准备【具体主题】的图书内容，想核对这件商品的出版社、ISBN、套装册数和当前版本。请问能否提供目录及相关主题的样页？商品页图片、封面或样页是否允许用于带货内容，范围是什么？如有样书申请、推广佣金或活动条件，也请提供当前说明。

不声称自己已有矩阵、销量或合作案例，不把“出版社可能寄样书”当必然结果。

**卡住怎么办：**没有权限进选品页，先用出版社公开目录和商品详情做“候选研究”，佣金与挂载状态填待核验；不必因此停止写审阅稿。找不到原书时，介绍文案只能证明介绍内容，不当作已经读过全文。

**完成检查：**有10本候选及来源；其中哪些已落实到实际商品、哪些仍是书目线索，一眼能区分。

## 第5步：算单笔收入，查质量，再筛出3本

### 5.1 手算一次，弄懂佣金

理论单笔佣金＝**实际计佣价格×适用佣金比例**。页面显示售价不一定等于计佣基数，活动、券、定向计划等条件要核对。

以下是虚构的算术教学，不是真实商品价格或收益承诺：

| 教学商品 | 假设计佣价格 | 假设佣金比例 | 理论单笔佣金 | 不能忽略的情况 |
| --- | ---: | ---: | ---: | --- |
| A 古建图解书 | 128元 | 35% | 44.80元 | 目录与本轮问题匹配仍需核验 |
| B 历史阅读书 | 69元 | 20% | 13.80元 | 不能只因为单价低就判定不好 |
| C 旅行套装 | 89元 | 30% | 26.70元 | 套装册数、样页和质量要确认 |

若一条视频实际花了90分钟、直接花费10元，只有一笔44.80元结算佣金，扣除这10元后剩34.80元，仍未计人力和其他成本。不要写成“这条视频净赚44.80元”。退款未结算时更不能提前记收入。

### 5.2 质量检查按顺序看

1. 出版信息：标题、作者、出版社和版本能否对应？
2. 内容：目录和样页是否支持你准备讲的问题？
3. 实物：版式是否清楚，图是否有用，装帧是否符合商品说明？
4. 评价：把“个人不喜欢内容”与“缺页、印刷不清、发错货”等具体问题分开记；看是否重复出现。
5. 服务：当前库存、配送与售后说明是否能查到？不承诺页面没有的服务。

课程的评分参考不是所有页面通用的刻度。平台未显示同一评分体系时，不硬套“4.5分”。

### 5.3 做保留、暂缓、淘汰三种决定

- **保留：**内容匹配、版本清楚、收益可比较、画面有办法。
- **暂缓：**看起来合适，但目录、计佣或样页还缺关键项；写清补什么。
- **淘汰：**已经发现明确质量问题、内容不支持，或你根本无法合理制作。

**教学决定：**A目录和样页尚未补齐→暂缓，补资料后再决定；B有充分内容支撑→可以保留；不能只按44.80、26.70、13.80从高到低选。

**完成检查：**留下3本入围书，每本有一句理由；选定1本主测、1本备用之前，再做第6～7步的内容检查。

## 第6步：选一种视频形式，控制第一条的难度

来源：[口播9856](https://scys.com/course/detail/156?chapterId=9856)、[金句9857](https://scys.com/course/detail/156?chapterId=9857)、[动态书单9858](https://scys.com/course/detail/156?chapterId=9858)。

| 形式 | 你需要准备什么 | 第一次怎么选 |
| --- | --- | --- |
| 单人讲解 | 一篇原创口播、一个声音、少量有用画面 | 优先选它，便于核稿与对齐 |
| 双人播客 | 有问有答的稿、两个可用声音、能分清角色的底图 | 喜欢对话表达时选，见附录B |
| 金句阅读卡 | 少量有来源的短句、底图、可读排版 | 可练排版；有播放不等于有购买意愿，见附录A |
| 动态书单 | 更完整的讲稿、多张对应画面、逐镜剪辑 | 熟悉基础后再做，见附录C |

### 6.1 先做一次“讲不讲得出来”检查

对3本入围书，每本写3个不同的问题。一个题目只做一个小承诺，例如“解释一个结构”“学会一个观察方法”，不在一分钟塞进整本书。

如果三题只是“这本书太好了、这本书值得买、这本书不能错过”，说明还没有提取内容。回去看目录样页，再写能独立回答的问题。

### 6.2 明确首轮怎么测

1. 选1本内容证据较充分的主测书，另留1本备用。
2. 给主测书写3个题目，例如观察顺序、一个构件问题、出发前怎样用书做功课；具体内容均须书或其他资料支持。
3. 三条先保持同一种形式、近似时长和相同主推商品，分别观察不同问题的反馈。
4. 先做好T01，再做T02、T03；从第一条剪辑返工中改进制作方式。

**注意：**不同题目、不同发布时间会同时影响数据；首轮是探索，不是严格的因果实验。后续要比较开头时，再用同一题目、同一商品和近似条件做版本对照。

**完成检查：**一张制作卡上写明`主测书｜备用书｜所选形式｜T01/T02/T03问题｜本轮主要观察什么`。

## 第7步：从资料里取事实，不让AI替你猜书

### 7.1 建立最小资料包

1. 保存实际商品信息和目录。
2. 选T01真正需要的两三处内容，保存样页、页码或可回看的来源链接。
3. 自己读一遍，划出准备讲的要点；不必先精读整本书才开始一条作品。
4. 另外找的背景资料单独标注，不能把它写成售卖书原话。
5. 资料涉及具体文物、结构或历史结论时，核对对象、年代、位置和适用范围；普通类比不能变成历史事实。

本项目B01～B04负责研究，M01～M04仍是商品方向，详见[双层书目](10_双层书目与15城映射.md)。用参考书查到一个机关，不代表主推商品也有那个机关的图解。

### 7.2 让AI先做“资料卡”，不要立即写营销稿

将有权使用的必要文本、清晰截图或页码资料交给AI，输入：

```text
我准备给【具体读者】讲【T01的问题】。
下面有实际商品目录/样页，也有补充资料，已分别标注。
请只依据这些材料输出：
1. 可以确认的事实，每条标来源和位置；
2. 原书观点与我的解释，分别列出；
3. 还缺什么，不能确定什么；
4. 适合一分钟左右讲清的一个小问题；
5. 商品能承接的阅读价值，必须有目录或样页依据。
不能虚构页码、人物引语、作者经历和书中案例。
【粘贴材料和来源】
```

### 7.3 人工对照3件事

1. 随机抽查AI列的事实，原页是否真的有？
2. 它是否把“可能”“某个例子”改成“一律”“全部”？
3. 它是否用书名猜出了根本没提供的章节？有就删除，重新要求基于现有材料。

**事实卡示例（只示范填法，不提供虚构证据）：**

| 编号 | 准备讲什么 | 证据位置 | 状态 | 怎么处理 |
| --- | --- | --- | --- | --- |
| F01 | 售卖版本有入门观察图解 | 实际目录/样页待补 | 待核验 | 补到前不写“本书逐步图解” |
| F02 | 本条采用先看轮廓再看细节的观察顺序 | 本版教学建议 | 可作为建议 | 不说这是唯一科学顺序 |
| F03 | 某个构件承担什么作用 | 对应专业资料待补 | 待核验 | 不先编结论或精确结构图 |

**卡住怎么办：**截图不清楚先重拍；AI看不到附件就粘必要段落；只有目录时先选目录层面的介绍角度，不能假装知道正文。缺核心事实就换一个有证据的问题。

**完成检查：**T01至少有可用资料支撑，成稿不依赖尚未补齐的关键断言。

## 第8步：写一条能念顺的原创口播

### 8.1 先选一个开头，不直接说“今天推荐一本书”

给AI同一问题，要求生成三类开头：提问、具体场景、可观察的差别。自己念出来，选最清楚的一条。

**教学示例：**

- 提问式：“第一次逛古建，不知道先看哪里？”
- 场景式：“走进一座老建筑，你拍完门口，又不知道该看什么了。”
- 观察式：“先别急着背构件名字，退后几步，看看这座建筑的轮廓。”

这些是原创表达示范，不代表已经验证的高留存开头；不要再加“99%的人都不知道”等无依据数字。

### 8.2 按五段写，给每段安排任务

| 段落 | 写什么 | 自己检查一句 |
| --- | --- | --- |
| 具体疑问 | 观众面对的一个问题 | 听完第一句知道要讲什么吗？ |
| 关系或场景 | 解释问题所需的位置、对象和背景 | 没去过现场的人能理解吗？ |
| 单点解释 | 按顺序把原因、观察方法或步骤说清 | 有没有堆术语、跳因果？ |
| 实际收获 | 下次看哪里、怎样做 | 能照着试一次吗？ |
| 自然引书 | 说明对应版本还提供什么 | 卖点能回到目录样页吗？ |

### 8.3 可复制写稿指令

```text
请根据下面已核对的资料卡，写一条原创单人讲解稿。
读者：【填写】；问题：【填写】；目标：先按60～85秒试读，不保证纸面即达标。
结构：具体疑问→必要背景/关系→讲清一个方法或机制→可做的观察→自然引书。
要求：用日常语言，不编故事、研究、专家背书和原书引语；
不要复制对标的开头结尾，也不要把未核对的资料写成商品卖点。
先输出连续口播正文；来源与待补项另列，不念给观众。
结尾只说明已被实际目录/样页支持的阅读价值；购买入口未定时不写购买指引。
【附定位卡、事实卡、实际商品信息】
```

### 8.4 贯穿案例：一条完整口播怎样长出来

**下面是虚构商品A的教学稿。训练假设：A的实际目录和样页已确认有入门观察图解；现实中目前没有完成这项商品核验。不能把这段当现成商品广告发布。**

> 第一次逛古建，不知道先看哪里？先别急着背构件名字，可以试试这个观察顺序。退后几步，先看整座建筑和屋顶的轮廓；再走近一点，看看屋顶下面有哪些层次，木头之间是怎样连接的；最后才看门窗和装饰。每到一个位置，只带一个问题：我现在看到的是什么，它和旁边的部分有什么关系？看不清就拍下整体和细节，回去再找资料核对，不用现场猜答案。这样走一遍，你带走的就不只有一张门头照片，还有几个能继续追问的问题。如果想系统练习，这本古建阅读书里的入门图解，可以作为下一步阅读的起点。先看目录和样页，选适合自己程度的版本。

这里的观察顺序是教学建议。若要把稿件改成“斗拱的某个结构怎么受力”，需要另外取得足以支持该机制的证据和图示。

### 8.5 试读、计时、改稿

1. 用手机录一次自然朗读，记实际秒数，不用把语速故意加快。
2. 太长先删重复铺垫和形容词，保留必要因果与步骤。
3. 太短先检查有没有把关键解释省掉，不为凑时长加空话。
4. 听到生硬书面语就改成你平时会说的句子。
5. 确认后保存`T01_口播_v02`，注明“进入配音版”。后面改了正文，配音、字幕和画面都要重新对照。

**完成检查：**连续念得顺、一个问题讲完整、引书有依据，实际试读时长已记录。

## 第9步：做配音，先把声音听明白

### 9.1 路线一：自己录音

1. 选安静房间，关掉持续噪声源，手机固定在大致相同的位置。
2. 先录10秒试听，确认没有爆音、摩擦声或明显回声。
3. 按段落录，不必每错一个字就从头开始。错句停一下，从完整句子重念。
4. 导入剪映后删掉错误那句和多余空白，保留自然呼吸和停顿。
5. 导出或保留剪辑轨，命名`T01_配音_v02`。

### 9.2 路线二：文本朗读

以下为剪映功能操作示例，名称和可用音色按安装版本为准：

1. 打开剪映，新建当期草稿。
2. 找“文本/新建文本”，粘入已经确定的口播。
3. 找“文本朗读/朗读/配音”等对应功能，先选一款你有使用权限的普通音色。
4. 先生成开头两三句，听字音、语速和停顿，满意后再处理全稿。
5. 页面提示字数上限时按完整段落分批，不硬切在半句话中；课程的500字是当时示例，不作为当前固定上限。
6. 同一条稿保持音色和参数一致；对不认识的字先核对读音，再单独重生对应整句。
7. 配音生成后，原始长文本如果会显示在画面上，把它隐藏或移出显示范围；保留声音，稍后再制作正式字幕。

### 9.3 最后必听四处

开头是否截字、专有名词是否读错、分段连接是否突变、最后一句是否完整。听完整条，记录最终配音时长。不能只听开头就进剪辑。

**卡住怎么办：**没有文本朗读权限就用本人录音；不能使用某个音色就换可用音色。音色“像名人”不是质量要求，不未经授权克隆真人声音。

**完成检查：**全稿声音可用、关键字音无误，配音版本与正文一致，并已得到真实时长。

## 第10步：分镜、准备图片，再决定是否生成视频

### 10.1 按意思分镜，不按固定字数生硬切

1. 打开最终口播和配音，标出内容从“问题”转到“解释”、再到“怎么做”和“读书”的位置。
2. 给每个段落分配一种画面任务。先判断这张图帮助观众理解哪一句。
3. 以最终配音记下近似起止时间；填完再去剪映实际调整。
4. 不同镜头要增加信息，不是同一个门头换五个角度。

### 10.2 给教学案例做五镜表

| 镜头 | 对应内容 | 需要什么画面 | 从哪里取得 | 不能省的检查 |
| --- | --- | --- | --- | --- |
| 01 | 不知道先看哪里 | 整体环境或建筑远景 | 自摄/许可清楚的素材 | 实际对象与口播不冲突 |
| 02 | 先看轮廓，再看层次 | 同一对象的简化观察示意 | 根据核对资料绘制 | 标“观察示意”，不伪造精确结构 |
| 03 | 看连接关系 | 对应部位的中景 | 可用实物照片 | 不能拿另一建筑细节冒充 |
| 04 | 整体和细节一起记录 | 自摄细节、拍照动作或记录场景 | 自摄/原创示意 | 画面能看清，不只装饰 |
| 05 | 回到图解阅读 | 实际商品封面或允许展示的样页 | 对应商品许可资料 | 训练稿尚缺真实商品，正式制作前补齐 |

本表只给画面任务，尚未生成或核验这些素材，不是已完成的分镜资产包。

### 10.3 哪些可以用AI，哪些先找实物资料

氛围书案、阅读场景、抽象概念可尝试AI。实际书封、书页、建筑身份、精确地图、结构细节优先用对应资料。不能让AI猜一个结构，再把它作为解释证据。

生图指令示例：

```text
用途：古建筑入门视频的阅读过渡画面。
画面：一张木质书桌，一本没有可辨识书名和正文的打开的书，旁边放记录纸和铅笔；
构图：竖屏9:16，主体在中央，上下留出后期字幕空间；
光线：柔和自然光，颜色朴素，画面清楚；
要求：不模仿真实出版社封面，不生成可识别商标，不添加虚构史料与引语。
这是一张氛围插画，不作为真实商品或历史现场照片。
```

### 10.4 从提示词到素材的操作

1. 打开选定生图工具，进入图片生成功能。
2. 先生成一张测试图，设定与用途一致的画幅；本项目首轮可用9:16，课程4:3居中留上下栏是另一种版式。
3. 检查主体是否清楚、有无多余肢体、乱码、错误构造和拥挤字幕区。
4. 只改一个明确问题，例如“主体太小，改成中景”，而不是连续换风格。
5. 下载可用原图，按镜头编号保存，记下生成工具、日期和实际许可信息；保留工具或平台要求的标识。
6. 其余图沿用相近色调和构图原则。文字标签、书名和箭头后期加，避免AI画错文字。

### 10.5 第一次可以先用静图

先把“声音+对应图片”剪通。确有需要展示运动时，再在图生视频入口上传可用图、描述单一动作，如“镜头缓慢推近书桌”。生成后看主体是否变形、细节是否漂移；有问题可退回静图。动态效果不保证数据更好。

**完成检查：**每段口播有可用画面或明确缺项，文件能对应镜头编号；缺核心实物图时，不拿虚构图片顶替后宣称真实。

## 第11步：在剪映里完成第一条片子

本节以常见电脑版剪辑功能说明操作顺序，未对你的当前安装版本逐项实测。找不到同名按钮时，按功能找；不会某项动画可以先不做，不妨碍基础成片。

### 11.1 新建草稿，导入声音和画面

1. 新建草稿，命名为当期作品编号，例如`T01_古建入门_v01`，不要打开旧片直接覆盖。
2. 在“媒体/导入”中选择最终配音和已选图片。
3. 把配音拖到时间线音频轨；把图片按镜头01～05顺序拖到主画面轨。
4. 把画布比例设为9:16。若第一张图使项目自动变成横屏，要主动改画布比例。
5. 点击一张图看预览：主体太小可合理调整位置和缩放，但不要为了隐藏生成标识而裁切。
6. 横图放竖画布时，可选择居中留边并用朴素背景承接；不要为了铺满画面切掉关键结构。

### 11.2 先对齐音画，再做效果

1. 从第一秒播放，听到下一段开始时暂停，在时间线上记住位置。
2. 选当前图片，把右边缘拖到对应位置；下一张从这里开始。
3. 图片边界吸附不准确时，放大时间线再拖，避免一小段黑屏或重叠。
4. 按同样办法处理全部镜头，确保配音讲哪个对象，画面就能对应哪个对象。
5. 最后一张覆盖到最后一句结束，不要声音没完先黑屏，也不要结尾剩十几秒空画面。
6. 如需轻微推近，在同一张图前后设置小幅位置或缩放变化；第一次不会关键帧，先保持静图。

**例子：**配音第18秒才讲“走近看细节”，那张细节图就不应在第5秒提前占满屏。镜头长度以真实配音为准，不照抄“每镜6秒”。

### 11.3 生成字幕，人工校对

1. 在“文本/字幕”中找“识别字幕/智能字幕”等功能。
2. 选择识别配音轨，确认语言后生成。若已有字幕，要先确定是否替换，避免叠出两层。
3. 对照最终口播逐句检查，优先修书名、作者、人名、地名和多音字。
4. 一屏太长就在完整词语或语义停顿处分行；不要把“古建筑”拆成两行来凑字数。
5. 选清楚的字体和对比明确的颜色，可加适量描边；先保证阅读，再考虑花样。
6. 把字幕放在画面中的稳定区域，避开主体细节，并给平台标题、头像和商品按钮留空间；具体位置用手机预览确定。
7. 逐句播放，修正明显提前或滞后。只有短句文本、没有音频对齐时，不叫完成时间码字幕。

### 11.4 只添加必要的画面文字

可加本条问题、必要示意标签和准确书名。书名与商品一致，不能让生成图上的错字进入成片。解释正文和字幕同时很长时，先减少固定文字，避免四层文字互相压住。

### 11.5 音乐和转场最后处理

1. 初版可以不加音乐，先确认声音清楚。
2. 使用音乐时先确认可用范围，选择不会干扰讲解的素材。
3. 开始播放配音，再慢慢提高背景音乐，直到有氛围但每个字仍清楚；这里不把某个分贝值当所有音源通用标准。
4. 镜头可直接切换；确需转场只选简单效果，注意转场是否造成画面变短、字幕跳动。
5. 最后再听一次整体，检查重复音轨、突然变大的音乐、音画尾部长度。

### 11.6 导出与手机复查

1. 点击导出，先看是否有付费素材或导出限制提示；不需要的付费效果可去掉。
2. 竖屏首轮可尝试1080×1920、30帧、MP4作为制作起点；按工具可选项和平台实际要求调整，不靠升到4K弥补模糊素材。
3. 命名`T01_预览_v01.mp4`。导出后打开这个文件检查，不只看编辑器预览。
4. 传到手机正常全屏播放：看书名、字幕和关键细节是否清楚，听开头结尾是否完整。
5. 需要修改就回草稿，另导`v02`；只有确认后的版本才命名为最终版。

**卡住怎么办：**主画面黑屏先查是否有轨道空隙；听见重音先查是不是两条相同配音同时播放；字幕两层先查原始长文本是否仍显示；没有声音先查轨道静音和导出是否含音频。

**完成检查：**实际导出的手机预览版可看、可听、音画对应；稿件、配音、字幕版本一致。制作耗时和主要返工已记录。

## 第12步：准备发布内容，再核对真实商品入口

来源：[发布9861](https://scys.com/course/detail/156?chapterId=9861)。本次只编写SOP，不执行账号修改、付费、对外联系或发布；下面是你实际执行时的步骤。

### 12.1 发布前先填一张发布卡

1. 标题：用观众的问题或实际收获，避免夸大。
2. 描述：补一句观看价值，与正文一致。
3. 话题：先选2～3个真正相关的词作为练习，不堆不相关热点。
4. 封面：选一帧清楚画面，加一句简洁题目，手机缩略图能看懂。
5. 商品：记录准备关联的实际版本和规格。
6. 标识：按当时平台和工具要求处理AI生成内容声明、素材署名及必要说明；不隐藏已有标识。

**教学填写：**

- 标题：第一次逛古建，先看这三个地方。
- 描述：先看轮廓，再看层次，最后看细节。带着问题走一遍，回来再查资料。
- 话题候选：古建筑、旅行阅读、读书分享。实际按页面可选话题处理。
- 商品：教学商品A，实际版本和链接尚未核验，因此本示例的商品挂载状态为待补。

### 12.2 手机发布顺序

1. 进入自己的视频号，找发表或上传作品入口。
2. 从相册选择已经确认的最终视频，先预览，确认没有选成预览旧版。
3. 设置封面，填写标题/描述与相关话题。
4. 若当前账号可关联商品，进入对应入口选择实际SKU；打开商品核对一次，不只看相似封面。
5. 若不能关联商品，检查是否有已可用的真实橱窗路径；没有就作为内容练习，不写“点左下角购买”。
6. 检查平台要求的声明与选项。位置只填真实且有意义的信息；不为了流量填写虚假地点。
7. 由发布操作者最后确认内容、账号、商品和版本，再点发布。
8. 发布后进入作品，检查状态和实际商品入口，保存作品ID或链接。不要把“上传成功”直接写成“已公开展示”。

### 12.3 电脑发布替代路线

1. 在浏览器打开[视频号助手](https://channels.weixin.qq.com/)，由本人扫码登录。
2. 先确认当前账号名称，再进入视频发布/作品管理相关入口。
3. 上传最终文件，填写封面、描述、话题、商品和必要声明。
4. 定时发布功能若实际可用，选择计划时间并记录；草稿、定时待发、审核中和已发布要分状态写。
5. 发布后仍去手机看一次实际呈现，确认文字和商品入口没有遮挡关键内容。

### 12.4 首轮怎么安排发布

先把T01做好并确认流程，再分批做T02、T03。可以用连续3天每天1条作为练习安排。记录时间即可，不需要为了课程里的“黄金时段”熬夜，也不直接套用每天10条等不同情境下的频率。

**卡住怎么办：**上传或挂载失败先记平台原始提示，检查文件、账号和商品条件；不重复盲点发布。作品审核中就记录待审，勿反复重发。商品选错时按平台允许的修改方式处理，保留记录。

**完成检查：**实际发布状态、作品ID、发布时间、实际SKU或“无挂载”已记录；成片里的购买指引与观众能看到的入口一致。

## 第13步：查看数据和回复真实问题

来源：[运营与复盘9862](https://scys.com/course/detail/156?chapterId=9862)。

### 13.1 发布后先做三件小事

1. 看作品能否正常播放、标题封面是否正确、关联商品是否对应。
2. 看是否有审核或违规通知，存在明确问题时先处理通知内容。
3. 回复真实提问；观众问怎么买，就按当前实际入口说明。没有权限时不承诺不存在的入口。

可以用本人身份补充一条实际信息，例如“本条先讲观察方法，具体术语还要结合对应资料核对”。不使用小号假装买家，不编“第68页亲测有效”等评价。

### 13.2 找到作品数据

1. 手机参考入口：个人视频号→创作者中心→数据或作品分析。
2. 找到对应T01，核对作品ID和发布时间。
3. 电脑可在视频号助手的作品管理/数据入口找同一条。
4. 商品数据可能在带货或交易相关页面，和内容播放数据分开；注意它显示的是作品、商品还是整个账号。
5. 按发布后24小时、72小时保存快照；第7天做批次回看。这些是本版统一比较窗口，不是平台保证的数据成熟时间。

### 13.3 看不懂数据时按这张表填

| 看到的字段 | 先问什么 | 能初步观察什么 |
| --- | --- | --- |
| 播放量 | 是这条作品、什么周期？ | 是否得到观看，不能代替订单 |
| 前3秒/5秒留存 | 后台怎么定义、分母是什么？ | 哪个位置容易离开，不能单独证明原因 |
| 平均观看时长/整体完播 | 总片长多少，同类时长吗？ | 内容是否被持续观看 |
| 评论/收藏/转发 | 实际问题是什么，是否相关？ | 观众想继续了解哪方面 |
| 商品曝光/点击 | 是作品里的商品入口，还是全店？ | 有无从内容进入商品的行为 |
| 成交/退款/结算 | 按什么归因窗口，有没有结算？ | 交易反馈与实际收入，不用未结算订单冒充利润 |

缺数据就留空并写“后台不可得”；0只用于后台真实显示为零。不要把“没有读到字段”写成“没有点击”。

### 13.4 一个算得明白的教学例子

以下全为虚构、同窗口且已核对口径的数据：T01播放1200，商品曝光500，商品点击10，已归因订单1。

- 若确认后台曝光和点击的定义可配对，商品点击率＝10÷500＝2%。分母是商品曝光，不是随意拿播放1200代替。
- 若确认订单与点击同口径，点击至下单比＝1÷10＝10%；只有1单，样本很小，不能预测后面每天的收入。
- 没有退款和结算信息，就暂时不计算实际净收益。
- 以上数字不能直接说明“标题不好”或“书太贵”，还需要结合脚本、评论和商品情况检查。

### 13.5 填到已有记录表

复用[发布复盘表](04_发布复盘表.csv)和[字段说明](04_发布复盘表说明.md)。一条新作品追加记录，不覆盖以前的试做稿；同作品新截点另留快照。填实际耗时，不用脑补“AI生成只要一分钟”。

**完成检查：**同龄窗口能对应具体作品，缺项清楚，真实问题已有记录。还没有数据时只记录状态，不急着归因。

## 第14步：根据数据决定下一条改什么

### 14.1 先检查“入口或内容有问题”，再猜观众偏好

| 实际情况 | 具体检查 | 下一步动作 |
| --- | --- | --- |
| 播放一直很少 | 是否仍待审核、是否有明确限制、题目与内容是否一致 | 先处理可确认的问题，再小批测试；不凭两三天就宣判账号没权重 |
| 前段流失明显 | 第一张画面是否清楚，开头绕不绕，配音有没有截字 | 保留题目和商品，重点改前几句与相应开场画面，保存新版 |
| 前段还行、中段掉得快 | 解释是否重复、术语太多、画面没跟上 | 删重复、补关键解释和对应画面，再听完整因果是否成立 |
| 观看尚可、商品点击少 | 是否真有商品曝光，引书是否相关，购买入口是否正常 | 先核入口，再改阅读价值表达；不立刻把原因归为价格 |
| 点击有了、成交少 | 样本和归因窗口、版本价格、商品页、配送和差评 | 把可能原因列为待验证，只改有根据的一项 |
| 成交后退款或成本高 | 真实退货原因、内容承诺、实物与版本、结算 | 修正商品或承诺，核实际成本后决定是否继续 |

### 14.2 把数据和原稿一起交给AI

```text
请帮我复盘一条作品，先列事实，再列最多3个待验证原因。
作品编号/形式/实际时长/发布时间：【填写】
数据截点和统计口径：【填写】
观看、商品、交易数据及缺项：【填写】
口播开头、正文、引书段：【粘贴】
真实评论和制作耗时：【填写】
不要用缺失数据推断转化，不要仅凭播放判定账号权重。
给出下一轮只改一个主要变量的方案；说明哪些内容保持一致、
需要继续记录什么，以及什么结果仍不足以下结论。
```

### 14.3 复盘用四句话写完

**虚构填写示例：**“T01在24小时有1200播放、500商品曝光、10点击、1个归因订单，退款与结算未知。评论有人问示意图在哪里，但还不能证明这导致未购买。下一条同题版本主要把示意图与解释对齐，保留商品和时长范围，记录相同窗口。等补到更多作品与结算数据后，再决定是否继续做这本书。”

没有明显可确认问题时，下一条可以继续验证另一个候选问题。三条探索稿出现差异不等于找到了因果；要继续少量重复验证。

**完成检查：**下一轮有一个具体调整动作及观察窗口；“优化文案、提升质量”太笼统，还需写成能操作的一句话。

## 附录A：如果选择金句阅读卡，具体怎么做

这条路线用于练习“短句、画面、节奏和排版”，仍需第1～5步的定位与商品核对。不能因为制作简单，就把100条随机拼接当稳定带货方法。

### A1. 先确定文字属于哪一种

- 原书短引文：核原文、作者、实际版本和页码，并确认使用范围；不能给AI编的句子加引号署成原书金句。
- 读书转述：说明是对书中观点的概括，保留资料位置，不能改变意思。
- 自己的阅读建议：明确作为个人表达，不冒充作者原话。

### A2. 做一条3张卡片的练习

**以下为本版原创阅读建议，不是任何书中的引文：**

1. 第一张：“逛古建前，先带一个问题。”
2. 第二张：“现场记下看见的，也记下没看懂的。”
3. 第三张：“回到书里，再把问题接起来。”

这个例子本身不是已核验商品卖点。实际引书另外核对目录，别随意贴一本不相关的书。

### A3. 逐项制作

1. 新建`J01_阅读卡练习`草稿，画布设9:16。
2. 导入3张许可清楚、风格相近的底图，放到主画面轨。
3. 为第一张创建文本，输入一句话，调整为清楚的两行或三行。
4. 选择同一字体、字号和位置，复制文本框到第二、第三张，分别改内容。
5. 文字和背景不够清楚时，加半透明底板或适当压暗背景，手机看清为准；不机械套课程的70%～75%透明度。
6. 自己按正常阅读速度读一遍，每张留够看清和理解的时间。课程的7秒打印机动画是示例，不是每张固定时长。
7. 想做逐字出现效果时，给第一张加文本动画，预览后再复制；文字还没出完就切镜头，需延长画面或缩短动画。
8. 音效和音乐可选，先确保文字读得完；音乐不盖住朗读。
9. 若添加商品封面和阅读说明，使用实际商品资料，保持句子与该书有关。
10. 导出手机预览，确认没有遮挡、错字、切边和未完成动画。发布与记录回到第12～14步。

**常见卡点：**一屏挤满字→先减为一个意思；动画太花→关掉再看能否读清；金句互动高却没点击→检查是否只是泛情绪内容、书与句子有没有真实关联。

## 附录B：如果选择双人播客，具体怎么做

### B1. 先把一段解释拆成问答

一个角色替观众问具体问题，另一个角色按资料回答；人物身份写成普通阅读分享者即可。不要用虚构专家、仿名人声音或电视台标识制造背书。

**教学对话示例：**

> A：逛古建时，名字一个都记不住，怎么办？
>
> B：先给自己减一点任务。这次只看整体轮廓，再记一个细节。
>
> A：看到了，可还是不懂它叫什么。
>
> B：把整体和细节一起拍下来，带着问题回去查。能分清“看到什么”和“还不知道什么”，就已经有下一步了。

这是本版的阅读方法建议。实际商品承接段仍需目录样页支持。

### B2. 两个声音怎样放进剪映

1. 把稿子按`A01、B01、A02、B02`编号，分别生成或录制完整句子。
2. A所有片段用同一音色，B用另一有权使用的音色。先试听四句，确认能区分且音量相近。
3. 将片段全部导入剪映，按问答顺序排入时间线；可分两条音频轨，便于识别角色。
4. 上一句结束后再接下一句，保留正常交流停顿。波形有空白时试听判断，不统一把停顿删成固定毫秒数。
5. 需要重生某一句时保留前后顺序与同一音色参数，防止一句忽快一句忽慢。
6. 对整个声音轨识别字幕，再核对角色与句子；可用简洁标签提示正在说话的人。

### B3. 准备和检查播客底图

可以用原创插画、简单两人对谈图，或用清楚的“A提问/B回答”版式。底图负责说明对话关系，不宣称真实节目或真实采访。对话讲到重要对象时可插入相应图示，避免长时间只有无关背景。

课程还演示了NotebookLM的“新建笔记本→添加文字资料→生成音频”路线；那类音频可能重组内容，不保证逐字复现最终稿。若使用，下载后必须完整听写核对新增事实、引书与结尾，再处理字幕和时长；不把生成后的扩写自动当成原书内容。该产品当前具体按钮、可用语言和时长选项未在本次逐屏验证。

**完成检查：**两个人物可区分、问答接得顺、没有新编事实或专家身份、字幕和声音一致。随后回第11步完成导出。

## 附录C：如果选择动态书单，具体怎么做

课程示例包含较长讲稿和40张以上画面的剪辑。这个数量说明制作负担，不要求第一条也凑满40张。需要多少镜头，取决于实际讲稿和可用证据。

### C1. 先做10～20秒片段验证制作能力

1. 选已经核过资料的一段，拆成3个连续信息单元。
2. 每个单元写“讲什么、观众看什么、素材来源、需要什么动作”。
3. 先只完成这3镜，确认配音、画面、字幕和运动都能对齐，再扩全片。

### C2. 为全片建立镜头清单

```text
镜头编号：
对应的原稿句子：
实际音频起止时间：
画面任务（解释什么）：
主体/地点/时代或场景：
素材来源与使用范围：
静图或视频：
需要的单一动作：
生成或拍摄状态：
检查结果与修改原因：
```

### C3. 先统一风格，再生成整批

1. 先选一镜作风格样张，检查它是否适合内容，而不是因为同行都用油画就一律用油画。
2. 固定常用画幅、色调和字幕留位，其他镜头沿用这些约定。
3. 一次完成少量镜头，检查后再继续；避免最后才发现整批构图不适合字幕。
4. 结构事实和地图按已核资料制作，人物、场景和物件前后保持一致。
5. 图生视频只描述需要的动作；生成后发现构件扭曲、物体凭空增加，就修正或换回可用静图。

### C4. 剪辑按音频顺序，不按下载顺序

1. 最终配音先上轨，再按句子放镜头。
2. 镜头跟着信息变化切换；一段解释没说完，不因“已满6秒”强行切掉。
3. 运动镜头和静图可以混用；统一检查运动方向、速度和是否影响理解。
4. 按第11步做字幕、声音、导出；较长作品分段检查后，还要从头到尾完整看一次。
5. 记录每镜返工原因，下一轮先改最耗时的一项。不能只记录AI生成耗时，忽略挑图和剪辑时间。

**完成检查：**信息量与实际片长匹配，画面承担解释任务。较长不自动意味着更有价值，镜头更多也不自动带来成交。

## 第一轮可以怎样安排

以下是教学排程，不会创建提醒或自动执行。每天可用时间不足就把一天拆成两天，不需要赶进度。

| 顺序 | 今天实际做什么 | 停下来时手里应该有什么 |
| --- | --- | --- |
| 第1天 | 第0～3步：准备、账号、定位、观察 | 账号卡、定位卡、10条观察记录 |
| 第2天 | 第4～6步：收集商品、比较、选形式 | 10本候选、3本入围、主测与备用、3个题目 |
| 第3天 | 第7～8步：核资料、写T01、试读 | 事实卡、进入配音的口播版本 |
| 第4天 | 第9～11步：声音、画面、剪辑 | 手机看过的T01预览版、耗时记录 |
| 第5天起 | 第12步：条件具备后实际发布，继续T02/T03 | 实际发布卡或明确待补项 |
| 每条发布后 | 第13～14步：统一窗口记数据、复盘 | 截点快照与一个主要改进动作 |

**你现在可以从第1步开始：先把账号状态和定位卡填出来。**如果已经准备好账号，就直接做第3步的10条观察；先完成一小段，再进入下一段。

## 使用课程经验时怎样判断

下面这些处理集中说明一次，执行时无需把它们念进视频：

| 课程中的经验或做法 | 本版实际采用的办法 |
| --- | --- |
| 固定年龄画像、开通门槛和保证金 | 查本账号当前后台，记录日期与实际要求 |
| 低播放短期换号、统一黄金时段、固定日更量 | 先查明确状态与数据，再做可承受的小批测试 |
| 爆款文案提取后保留开头结尾 | 学问题选择与表达方法，从资料和商品价值原创组织 |
| 用拼音代替词语、改动固定比例即可合规 | 核对说法本身与证据，不用字符替换或比例承诺通过审核 |
| 缩放画面去掉AI水印、小号伪装用户互动 | 保留必要标识，用真实身份回应实际问题 |
| 健康案例和效果数据 | 未核实的医学内容不进入本手册成稿；免责声明不替代事实核验 |

本次没有访问你的实际橱窗、付费套餐和作品后台，也没有制作或发布教学案例。正式选书与发布时再补对应商品、素材和账号事实，不把教学假设当成已完成结果。

# 05｜爆款知识库与复盘（首轮审阅版）

本库只处理“林睿读书&书在橱窗”50条、“锦绣千秋录”30条。2026-10-15 本地筛选结果：80条逐条留痕，68条纳入地理、古建、古城、相关引书研究，12条因题材或健康功效风险暂排除。**纳入不表示史实已核、销量已验证，也不表示可以复制竞品文案。** 80条全文语义状态仍为 AI_PENDING；本轮仅使用已有转录做定向人工筛选和少量外部事实核对。

## 四部分交付

1. [钩子与引书结构库](01_钩子与引书结构库.md)：研究结构、短摘证据、适用条件、分商品引书草案。
2. [单点选题排期](02_单点选题排期.md)：从长视频拆出10个候选，先选5题；[5条完整试做稿](05_五条试做稿.md)含口播、字幕、画面、审阅状态。
3. [短片生产SOP](03_短片生产SOP.md)：60～90秒规格、交接 Antigravity 的最小输入，以及现有脚本的覆盖风险。
4. [发布复盘字段与用法](04_发布复盘表说明.md)及[空白记录表](04_发布复盘表.csv)：只填实际数据。

## 检索入口与证据级别

- [80条筛选台账](00_两账号80条筛选台账.jsonl)：每行有 `video_id`、账号、纳入判定、题材、转录绝对路径、开头ASR短摘、书名和商品动作线索。自动提取的短摘与书名线索只供定位，重点条目在结构库内按原转录复核。`明确书名及商品动作`仅表示转录同时出现，不代表同一商品版本或实际挂载已核。
- 竞品转录及既有静帧：只能证明“稿中怎样说/有限画面怎样展示”，不能证明排名、数字、史实、商品版本或带货效果；ASR专名和口误仍待听核。
- 公共机构页面、馆藏目录：可支持对应的公开事实和书目元数据；不能自动证明竞品橱窗售卖的是同一版本或取得图片、内页的商业展示许可。
- 首轮试做稿是**可审阅、可试读的原创草稿**。书籍橱窗链接、对应章节、允许展示的内页、素材及配音权利核实后，才能进入可发布审查。

## 当前决策

先试做5题，复核实际商品和口播时长，制作少量样片，再用真实数据评估能否扩为一周30题和每天3～5条。重复出现的溶洞、古城、山西木构、秋景等只标为“待测试候选”；没有播放、商品点击、成交、制作耗时数据，不作销量或产能结论。

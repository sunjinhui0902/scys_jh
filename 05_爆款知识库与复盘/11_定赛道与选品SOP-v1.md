# 定赛道与选品 SOP-v1

版本：v1｜整理日期：2026-10-16｜状态：待首轮实测。

目标：从一个明确的读者需求出发，选出能讲、有内容依据、有收益空间的实际图书商品，再用少量原创视频获得反馈。

依据：[生财《02.定赛道&选品》](https://scys.com/course/detail/156?chapterId=9853)，所属课程为《AI 视频图书带货（视频号）｜2026 年 3 月航海》。本次已通过 MCP 完整读取章节文字，图片案例未逐图核验。本文是方法归纳和执行设计，不是课程全文转载，也不代表平台当前官方规则。

课程提供的骨架：看需求与同行数据→选细分赛道→筛选图书→判断内容与画面能否制作→测试。本版补充了记录模板、版本核对、首轮数量和复盘动作；这些补充均为试行安排。

## 一眼看懂流程

确定读者与问题 → 找近期需求证据 → 定一个细分赛道 → 收集10本候选 → 核对商品与收益 → 筛出3本 → 确定1本主测书 → 做3条原创视频 → 实际发布并记录 → 复盘后继续或调整。

**第一轮建议：10本候选、3本入围、1本主测、1本备用、3条视频。**这是控制工作量的小批量方案，不是成功率标准。三条视频只能提供初步反馈，不能据此证明赛道有效或无效。

## 第1步：用一句话确定读者和需求

**怎么做**

1. 有账号后台数据时，先看实际粉丝与观看人群；没有时，把受众写成“待验证假设”。年龄不直接套用课程中的平台整体画像。
2. 写下对方最关心的一个问题，以及看完内容后希望得到的具体收获。
3. 暂时只选一个方向，不同时混做历史、育儿、养生等不同需求。

填写句式：**给____人，讲清____问题，帮助他们____，图书承接____阅读需求。**

本项目示例（待验证）：给喜欢城市旅行和历史的读者，讲清古城与古建筑中一个看得见的机关，帮助他们下次参观知道看哪里，图书承接系统了解城市文化的需求。

**留下什么：**一张定位卡，写明“受众、问题、收获、图书阅读需求、已有证据/待验证”。

**何时进入下一步：**能用一句具体的话说清楚；“做历史、卖好书”还不够具体。

## 第2步：找近期需求证据

**怎么做**

1. 打开视频号搜索，围绕需求搜3～5组词。本项目可先用“古建筑怎么看、古城旅行、山西古建、历史名城、园林为什么”等作为检索词，不预设它们一定热门。
2. 本轮手动挑10条相关作品，覆盖至少3个账号；兼顾中小账号和头部账号，查看发布日期，避免只看一个多年累计的高赞作品。
3. 记录作品链接、账号、发布日期、采集日期、讨论的问题、可见互动、商品线索及评论中的真实提问。粉丝数可见时记录，不能仅凭一条高赞作品就称“低粉爆款”。
4. 在当前账号可用的微信小店带货助手、带货中心等官方页面核查商品信息。入口名称按当前实际界面寻找；暂时不用购买第三方数据会员。

**留下什么：**10条需求观察记录。优先写“哪些具体问题反复被问到”，少写“这个赛道很火”。

**何时进入下一步：**多个独立来源出现相近需求，且自己能提供有依据的回答。只有点赞、没有播放或成交时，只能判断有互动线索，不能判断带货效果。

## 第3步：确定一个细分赛道

**怎么做**

把候选方向按四个问题逐项检查，填“有证据、待验证、不适合”：

| 问题 | 实际检查动作 |
| --- | --- |
| 需求是否具体？ | 从观察记录里找真实提问，能否列出3个不同问题？ |
| 能否持续讲？ | 不依赖重复文案，能否先列出10个有差别的选题？ |
| 是否做得出来？ | 能否找到可靠资料和适当画面，制作成本是否承受得起？ |
| 是否有合适商品？ | 是否存在可核对版本、内容相关、收益可接受的候选书？ |

本项目首轮可试“古城与古建筑的具体机关”，暂不同时扩成泛历史。它是基于现有创作方向提出的测试选择，不是本次新验证的市场结论。

**留下什么：**一个主赛道、一句选择理由、10个问题选题。

**何时进入下一步：**四项能给出具体回答；商品仍有缺项可以继续筛书，但不能写成已能挂售。

## 第4步：收集10本实际候选书

**怎么做**

1. 从当前可用的官方选品页面、同行实际商品和出版社官方渠道找书。其他平台榜单只作候选线索，不能直接推断视频号也能卖。
2. 以实际商品为单位记录：书名、作者/出版社、版次或ISBN、套装组成、商品链接或SKU、采集时间。
3. 补充当时价格、可见佣金及活动条件、库存/配送信息、可见评价与差评问题。不可得字段填“待核验”，不能填0。
4. 对照需求写一句“这本书帮助什么人解决什么问题”。写不出来的暂不进入主测名单。

**留下什么：**10本候选书清单，书与具体商品能够对应。

**何时进入下一步：**候选书有来源，不是AI凭空列的书名。项目现有M01～M04只是商品方向，B01～B04是研究参考书，均须另外核对实际售卖版本。

## 第5步：核对收益与商品质量

**怎么做**

1. 按同一个商品、同一时点计算理论单笔佣金：**实际计佣价格×适用佣金比例**。如有定向计划、优惠券或活动条件，按实际计佣说明记录；规则不清楚就标待核验。
2. 课程提出过50～200元价格区间、30%以上佣金初筛，以及“佣金超过20%或单笔超过20元”的参考。这些不是统一硬门槛；本轮先比较实际每单收益与内容匹配度。
3. 查看出版社、版本、装帧、目录和样页；检查差评是否集中在印刷、缺页、货不对版、内容不符等问题。
4. 不能把理论佣金称为利润。实际发布后另记结算佣金、退款影响、样书/制作等成本和投入时间；没有退款数据就不估填。

**留下什么：**每本书的“收益信息、质量问题、待核验项、保留/暂缓/淘汰及原因”。

**何时进入下一步：**明确质量或版本问题的商品排除；缺少关键信息的商品暂缓主测。高佣金不能抵消内容不匹配。

## 第6步：筛出3本，检查能否持续做内容

**怎么做**

1. 对最有希望的3本书，各找实际目录、样页或样书，写出3个彼此不同的视频问题。
2. 每个问题对应一个可核对的内容位置，以及一个观众能理解的收获。
3. 为每个问题列出需要的画面：实物、结构示意、地图、细节或阅读场景；判断哪些已有、哪些要补。
4. 用AI整理资料和提出表达方式，再人工核对。AI没有读到正文时，不让它断言“书里写了什么”；回答平庸时先检查输入资料是否充分。

可直接使用的指令：

> 根据我提供的实际商品信息、目录和样页，为【目标读者】提出3个不同的视频问题。每个问题列出观众收获、资料位置、需要的画面、自然引书理由。区分原书内容与补充资料；资料不足写待核验，不虚构章节、引语或商品卖点。

**留下什么：**3本书各3个选题的内容卡，共9个候选问题。

**何时进入下一步：**入选书有真实内容支撑，也能合理制作。参考书支持的事实不能自动变成售卖书的卖点，AI画面不能充当真实文物或商品内页证据。

## 第7步：确定1本主测书和1本备用书

**怎么做**

1. 优先选择需求明确、内容证据充分、制作负担可控、商品信息清楚的书。
2. 从主测书的候选问题中选3个不同题目，统一内容形式和大致时长，每条只讲清一个问题。
3. 给每条设不同编号，固定主测商品，写清“这次主要观察哪个问题更能引发观看、点击和后续阅读兴趣”。

**留下什么：**1本主测书、1本备用书、3条选题和各自观察目标。

**何时进入下一步：**每条能明确回答“为什么看、看完得到什么、为什么接这本书”。三条题目不同，这轮只是探索，不是严格控制变量实验。

## 第8步：制作3条原创视频

**怎么做**

1. 按[带货内容执行标准](09_带货内容执行标准.md)，完成“具体疑问→空间关系→单点机制→现场观察→自然引书”。
2. 按[短片生产SOP](03_短片生产SOP.md)做口播、试读校时、五镜方案、配音和字幕。项目当前60～85秒只是制作目标，以实际配音为准。
3. 每条使用独立工程和新文件名，先预览再完成成片。记录实际总耗时及主要返工原因。
4. 口播只承诺书里确有支持的价值；商品信息未齐时可以完成审阅稿，具体购买指引留到核实挂载后补。

**留下什么：**3条可审阅的原创作品及制作卡，事实、素材、商品和耗时能够追溯。

**何时进入下一步：**事实与商品对应、图文和音字对应、手机观看清楚；本片涉及的素材许可、声音使用和AI标识已处理。

## 第9步：实际发布，按统一窗口记数据

**怎么做**

1. 查看当前账号真实带货权限和挂载条件，以当时官方界面为准，不套用课程中的固定粉丝门槛。执行发布需另有明确授权；本次交付只生成SOP，不执行发布。
2. 权限具备时核对实际挂载SKU；权限未具备时可做内容测试，但不把没有购买路径的结果解释为商品转化测试。
3. 首轮可分3天每天1条，记录实际发布时间与作品ID；该节奏只是工作安排。
4. 各条按发布后24小时、72小时记录同龄数据，第7天再做一次批次复盘。窗口可以调整，但同一轮保持一致。
5. 复用[发布复盘表](04_发布复盘表.csv)及[字段说明](04_发布复盘表说明.md)，追加新作品记录，不覆盖历史行。

记录：播放、前段留存、平均观看、完播、互动、商品曝光、商品点击、成交、退款、结算佣金及制作耗时。后台不给的字段留空并说明；0只表示实际显示零。计算比率前先确认分子、分母和窗口一致。

**留下什么：**每条作品在明确截点的数据快照及实际发布状态。

**何时进入下一步：**同龄窗口的数据能对应到作品和商品。只有播放量时，就只分析观看表现。

## 第10步：每轮确定一个主要调整动作

| 观察到什么 | 先检查什么 | 下一轮怎么做 |
| --- | --- | --- |
| 播放少，尚无其他数据 | 发布状态、违规提示、题材与受众匹配、信息是否清楚 | 补看可用数据，改一个明确问题继续小批测试；不因两三天低播放直接换号 |
| 前段流失明显 | 开头是否具体、画面是否对应、表达是否绕 | 保持商品与主题，重点改开头，另记新版 |
| 看得下去，商品点击少 | 是否有真实商品曝光、引书是否自然、书与问题是否相符 | 先确认购买入口，再调整引书；不只看播放推断购买意愿 |
| 有点击，成交少 | 数据归因窗口、商品页、价格、版本、配送与评价 | 形成待验证原因，下一轮只调整有证据支持的一项 |
| 有成交，退款或成本高 | 结算数据、退货原因、承诺与实物是否一致 | 修正承诺或商品选择，按结算和实际成本评估是否继续 |
| 数据缺失或样本很少 | 哪些结论还缺证据 | 记录“暂不能判断”，补数据或再做一小批，不宣布成功或失败 |

**留下什么：**一段复盘，固定写4句：①观察事实；②待验证原因；③下一轮只改什么；④保留什么。

继续某本书或扩大产量前，看是否多条作品出现可重复信号、制作耗时能否接受、商品反馈是否稳定。出现一单只是一次观察；扩量阈值在有自己账号的基线后再设。

## 可直接复制的记录模板

### 定位卡｜每轮1张

- 批次与日期：
- 目标读者及依据（没有依据写假设）：
- 读者具体问题与期待收获：
- 主赛道与10个候选问题：
- 本轮主测书、备用书：
- 本轮3条选题及主要观察目标：

### 候选书卡｜每本1张，先填10本

- 书名/出版社/版次或ISBN/套装组成：
- 实际商品链接或SKU/采集时间：
- 目标读者/解决的问题：
- 计佣价格/佣金比例/活动条件/理论单笔佣金：
- 目录样页来源/内容位置/3个候选问题：
- 画面来源/缺项/预计制作难点：
- 可见评价与质量问题/库存配送信息：
- 结论（保留、暂缓、淘汰）及理由：

### 需求观察卡｜每条1张，首轮填10条

- 链接/账号/可见粉丝数：
- 发布日期/采集日期：
- 讲的问题/可见互动及统计口径：
- 评论中反复出现的需求：
- 商品线索/自己可原创补充的角度：
- 缺失数据/不能据此得出的结论：

## v1的使用边界与升级方式

本版未完成真实账号、实时商品、佣金和转化验证。它不预设平台用户年龄、算法偏好、换号标准或销量门槛。课程中的历史案例、销量与经验判断不能作为本账号收益承诺。

第一轮完成后，依据实际选品难点、制作耗时和同窗表现修订v2；保留本版和原始记录。缺商品信息先补商品，缺观看数据先补观看，缺交易数据就不推断成交。暂不为了学习启动全量竞品重分析、购买工具或铺矩阵。

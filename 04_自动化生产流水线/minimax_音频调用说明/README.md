## 二、什么时候用什么音色

### 2.1 主线三音色（口播解说，默认用这三个）

| # | 名称 | 引擎 | 音色 ID | 语速 | 音调 | 什么时候用 |
|---|---|---|---|---|---|---|
| 1 | **央视纪录片·沧桑历史男声** | Edge | `zh-CN-YunjianNeural` | `-8%` | `-6Hz` | **默认首选**。大历史、古建国宝、重大文化通史类带货。低频极厚、从容沉静、字正腔圆，文史底蕴与权威感极高 |
| 2 | **文化讲书·自然叙事男声** | Edge | `zh-CN-YunxiNeural` | `-4%` | `-1Hz` | 大众文化读物、手绘指南、历史趣味科普。语速自然、娓娓道来，不压场 |
| 3 | **三晋风味·关中厚重女声** | Edge | `zh-CN-shaanxi-XiaoniNeural` | `-4%` | `+0Hz` | 晋商、关中、黄土高原、乡土地域文化。地域识别度极强 |

> **选择逻辑**：音色要匹配**题材的分量**和**受众熟悉度**。讲大历史用 1（压得住），讲轻松科普用 2（不吓人），讲地域文化用 3（有味道）。

### 2.3 克隆音色（方案 A）：只在需要「特定声线」时用

| 用途 | 参考音频 | 能不能用 |
|---|---|---|
| 复刻**我们自己的**账号声线 | 包内 `01_音色/克隆参考_方案A/参考片段_食力日子_27.042s_9.052s.wav` | ✅ 可以（我们自己账号的成片音轨） |
| 竞品 13 条口播 | `02_公共资产库/竞品口播人声_20261116-17/` | ❌ **绝对不可以**（见 §六红线） |

> **包内已备好可直接用的克隆参考**：`参考片段_…wav`（9.05 秒，整句边界）+ `参考文本.txt`（26 字，逐字对应）。
> 片段起点与终点都落在语音停顿处，含 2 个完整句子：「那一排一排的陶俑，每一个脸都不一样。您跟孩子讲，这是两千多年前秦始皇的陪葬品。」
> 参考文本用 **Silero VAD 切分语音段定位边界 + 三种提示词 ASR 交叉复核**，三路结果一致。
> 来源：`01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav`（我们自己的成片音轨，55 MB 全长不适合直接喂，脚本需切段）。
>
> ⚠️ 该片段是**成片音轨原样**，含混音 BGM 底噪（停顿间隙约 −36 dBFS、低于人声约 24 dB），不是纯干声。
> 克隆音色若不够纯，换一段参考即可；**别拿竞品音频当参考**。

**克隆音色不继承参数**：F0 由参考音频决定，调不动。要什么音高就换参考音频，不要指望调参。

## 四、怎么调（命令）

### 4.1 Edge-TTS：免费、免密钥、主力路线

```bash
# 单句试音（换音色只改 voice/rate/pitch）
python -c "import asyncio,edge_tts; asyncio.run(edge_tts.Communicate('今天我们讲的是平遥古城','zh-CN-YunjianNeural',pitch='-6Hz',rate='-8%').save(r'out.mp3'))"
```

| 参数 | 默认基准 | 说明 |
|---|---|---|
| voice | `zh-CN-YunjianNeural` | 央视纪录片男声 |
| rate | `-8%` | 语速偏慢，纪录片腔 |
| pitch | `-6Hz` | 音调压低，低频更厚 |

### 4.2 MiniMax TTS：自有 key、六声线、情绪化对白

```bash
# 用仓库配置合成
python scripts/voice_api_tts.py --config config/voice_api/config.yaml --pack

# 只重做某一句（不重复消耗额度）
python scripts/voice_api_tts.py --role 奶奶 --text "你也在看着它呀。"

# 临时试别的音色/情绪/语速
python scripts/voice_api_tts.py --role 男宝 --text "爷爷！我嘴冒烟了！" --voice-id "Chinese (Mandarin)_Straightforward_Boy" --emotion surprised --speed 1.08

# 严格禁止新增付费请求（只允许复用已合成结果）
python scripts/voice_api_tts.py --pack --no-new-minimax
```

**配置**：`config/voice_api/config.yaml`（**含密钥，不可外传、不可入库**）。
换电脑时用 `config/voice_api/config.example.yaml` 复制一份填 Key，或用环境变量 `MINIMAX_API_KEY`（环境变量优先）。
中国区 key 用 `minimaxi`；国际区改 `minimax.io`。模型 `speech-2.8-hd` / `2.8-turbo`（2.8 系列才支持 `<#0.35#>` 停顿标记与 `(laughs)(sighs)(breath)` 语气词）。

### 4.3 E2-F5-TTS 克隆：方案 A、免费免 key

**用包内已备好的参考片段**（在 `03_调用脚本/` 目录下执行）：

```bash
# 第一步：干跑，只切句检查，不发请求
python scripts/clone_voice_ztts.py \
  --ref-audio "../01_音色/克隆参考_方案A/参考片段_食力日子_27.042s_9.052s.wav" \
  --ref-start 0 --ref-duration 9.052 \
  --ref-text "../01_音色/克隆参考_方案A/参考文本.txt" \
  --script "<你的口播文案.md>" \
  --out-dir "./克隆输出" \
  --chunk-min 18 --chunk-max 40 --dry-run

# 第二步：正式合成（去掉 --dry-run）
```

| 参数 | 建议值 | 说明 |
|---|---|---|
| `--ref-duration` | 5~15 秒 | 参考片段长度，语义要完整 |
| `--chunk-min/--chunk-max` | 18 / 40 | 每段字数，对应竞品短句快切节奏（句长 1.7~2.5 秒） |
| `--dry-run` | 先跑 | 检查切句是否有腰斩词组、平均字数是否在区间 |

**口播文案格式**：`clone_voice_ztts.py` 会自动抽取 Markdown 里的 `## 纯净口播文案` 段
（标题行可带括号补充说明），抽不到时至少会剥掉 Markdown 标题与分隔线，不会把标题当口播念出来。

**已知局限**：E2-F5-TTS 逐段独立合成，段间音色会漂；公共免费空间，稳定性不由我们掌控 → **必须保留 Edge / MiniMax 作兜底**。

### 4.4 BGM：归一与替换

```bash
# 把候选归一到推荐电平（源 mean = -23 dBFS，峰值限 -3 dBFS）
python scripts/competitor_audio_audit/bgm_candidates.py normalize "<候选>.mp3" --target-mean-db -23 --peak-cap -3

# 校验任意本地音频（时长 / mean / peak / 是否疑似含人声）
python scripts/competitor_audio_audit/bgm_candidates.py check "<文件>.mp3"

# 单条视频换 BGM（工程内覆盖，不动公共库）
copy "<归一后的候选>.mp3" "03_视频成片与工程\<项目名>\assets\audio\bgm_guofeng.mp3"
```

## 六、电平规范（**最容易踩的坑**）

管线增益是**相对值**，混音后 BGM 的实际电平完全由**源文件电平**决定。

| 项 | 基准 | 说明 |
|---|---|---|
| BGM 源 mean | **−23 dBFS** | 归一后的源文件电平 |
| BGM 源 peak | ≤ −3 dBFS | 软限幅，避免与口播叠加削顶 |
| 人声源 mean | ≈ −24 dBFS | Edge 云健 −6Hz/−8% |
| 管线增益 | 人声 ×1.4125（+3 dB）<br>BGM ×0.2239（−13 dB） | **不变** |
| 混音后 BGM | ≈ −36 dB | 比人声低约 **15 dB**，托底不抢戏 |

**⚠️ 旧版 BGM 源是 −52.9 dBFS**，叠加 −13 dB 后混音内 −65.9 dB，**比人声低 45 dB，实际听不见**。
换任何新曲都必须先归一到 −23 dB 再进管线，否则等于没换。
旧版留档：`01_配音与音色库/背景音乐库/_原始备份/bgm_shili_guofeng_原始-52.9dB.mp3`，包内为 `02_背景音乐/默认_食力过日子_国风古琴_原始-52.9dB_回退源.mp3`。

**包内 36 首授权候选的实测电平**（2026-11-20 用 ffmpeg `volumedetect` 逐首实测，非标称值）：

| 档位 | 目录 | 实测 mean | 实测 peak | 结论 |
|---|---|---|---|---|
| B 档 | `授权候选_B档_可听见_mean-23dB/`（18 首） | −23.3 ~ −23.2 dBFS | 最高 −2.4 dBFS | ✅ 达标。峰值软限幅有 ≤0.6 dB 过冲，但离 0 dBFS 很远，不会削顶 |
| A 档 | `授权候选_A档_与现状一致_mean-53dB/`（18 首） | −53.2 ~ −53.1 dBFS | 最高 −31.6 dBFS | 回退用。A 档目录名沿用「与现状一致」口径标 52.9，实测为 53.1~53.2 |

两档是**内容不同的两套文件**（逐首 SHA-256 不同），A 档同样听不见，换回它等于没换。

## 七、合规红线（不可越过）

| # | 红线 | 依据 |
|---|---|---|
| 1 | **剪映「商用音乐」不能用于视频号**。授权范围只有「剪映、抖音」两平台；除非曲目页另注「全渠道」 | 剪映《商用音乐说明》原文 |
| 2 | **CC BY-NC 一律不用**（禁止商用），带货视频属商业使用 | CC 许可定义 |
| 3 | **竞品 13 条口播与竞品 BGM 不进成片、不做克隆参考、不进任何恢复包** | 仓库约定 |
| 4 | **不输出、不外传 `config/voice_api/config.yaml` 的密钥** | 仓库约定 |
| 5 | 付费商用音乐须留**授权书**（猴子音悦 / 光厂 / 100audio 等） | 平台规则 |
| 6 | 克隆音色**不得对外宣称为某位真人本人** | 伦理与法律 |
| 7 | Mixkit / Pixabay 素材**不得单独转售或再分发**，随成片使用没问题 | 各站许可 |

我们属**带货变现账号（橱窗 / 小黄车）= 高风险主体**：非商用不等于安全，片段短也只是可能减轻赔偿，不免责。

## 十、边界（诚实标注）

- 音色与 BGM 的**曲风判定来自多模态听感模型，不是人工试听**；定稿前请试听
- **Silero VAD 会漏判含人声曲目**（实测 3/21），VAD 结果只能当参考，必须叠加听感
- **克隆音色尚未做完整合成 + 试听**（仅切分逻辑 dry-run 验证过）；段间音色会漂是固有风险
- **E2-F5-TTS 稳定性不由我们掌控**，不可作为唯一生产依赖
- 包内克隆参考片段的**参考文本由 ASR 交叉验证得出**（三路提示词一致），但仍建议正式克隆前人工听一遍原片段确认
- 包内克隆参考片段**含成片 BGM 底噪**（间隙 −36 dBFS，低于人声约 24 dB），不是纯干声
- BGM 候选池共 176 首（Mixkit 168 + FreePD CC0 8），本包只收 18 首首选；全部候选的 URL 与指纹在 `选曲清单.json` 与仓库 `02_公共资产库/授权BGM候选_20261119/` 里，可按需重拉
- **Pixabay 未纳入**：国风资源最丰富，但对脚本直接 403，需人工在浏览器下载
- "适合什么赛道"是**曲风推断**，不是平台数据验证过的结论；实际完播与转化要上线后看数据
- 包内 `03_调用脚本/` 只含音频链路脚本，**不含剪映草稿字体素材与固定书本实拍资产**；这两个走恢复包的 core 组

## 一、商业模式与核心定位

### 1. 目标客群画像
* **年龄层**：35岁 ~ 60岁+（中老年、文旅爱好者、文史自驾游群体、高知阅读群体）。
* **心理痛点**：
  * 热爱中华传统文化与古迹，但看不懂复杂的古建力学名词（如“侧脚”、“升起”、“减柱造”）。
  * 厌恶花里胡哨、语速极快的年轻人快餐解说，偏好**沉稳、厚重、权威、有文化底蕴**的纪录片风格。
  * 对**“物理力学奇迹”**、**“千年不倒”**、**“民族智慧与文化脊梁”**有极强的情感共鸣。
* **变现路径**：文物解密 ➔ 痛点呼应 ➔ 权威大书推荐（图书带货）/ 文旅线路推荐。

### 2. 核心创作原则（三大戒律）
1. **绝不纯靠AI生图做正片**：纯AI图缺乏历史真实感，带有油画质感和英文乱码，极易被懂行的用户喷为“垃圾假片”。
2. **拒绝空洞华丽的AI废话文案**：禁止出现“岁月如歌”、“光阴荏苒”等无意义堆砌，只讲硬核事实、具体数字和力学原理。
3. **国内受众全中文视觉**：封面、解密爆炸图、典藏图书画面一律严禁出现英文字母，强化华夏文化沉浸感。

## 三、文案去AI化重塑与分镜编排

以第1期《山西古建三大奇迹》为例，全片严格控制在 **82 秒（1分22秒）**，拆分为 **39 句极短句（单句 5~9 字）**。

### 1. 结构配比金字塔
* **0s ~ 13s（黄金 Hook，留存率核心）**：
  * *话术*：“从五代到元代的木构国宝，全国大半都在山西。但90%的人不知道，这里还藏着三大建筑奇迹：断了梁的殿、抽掉柱的堂、拆散又拼回来的宫。”
  * *技巧*：用权威宏观地理引出强烈悬念，一句话抛出三个奇迹钩子。
* **14s ~ 30s（奇迹一：高平崇明寺·断梁殿）**：
  * *话术*：“中佛殿的主梁，竟是用两截短木拼接的！古代匠人在接缝下方，加了一道顺栿串承托，用天才的力学平衡，稳稳扛过了一千多年。”
  * *技巧*：揭示矛盾（梁居然是断的） ➔ 揭秘原理（顺栿串力学支撑）。
* **31s ~ 45s（奇迹二：朔州崇福寺·减柱造）**：
  * *话术*：“走进弥陀殿，你会发现正中央空旷无比。原本该立金柱的地方，被硬生生减去了整整四根，靠人字斜拱跨空支撑，创造出金代辽阔的礼佛空间。”
  * *技巧*：移步换景 ➔ 视觉冲击（极其空旷） ➔ 给出数据（减去整整4根金柱）。
* **46s ~ 64s（奇迹三：芮城永乐宫·大搬迁）**：
  * *话术*：“六十年代修三门峡水库，原址面临沉入水底。专家们把整座元代古建筑，以及上千平米的朝元图壁画，切割成数百块，整体往北搬了四十里，竟然没有损毁一砖一瓦。”
  * *技巧*：水淹危局（制造紧张感） ➔ 现代抢救工程奇迹 ➔ 毫发无损的震撼。
* **65s ~ 82s（精神升华与带货转化 CTA）**：
  * *话术*：“这一梁一柱之间，刻满的是中国古人的通天智慧。如果你也想看懂中国古建，一定要读读这本《中国古建筑》。里面把结构图解和绝美壁画讲得明明白白。翻开它，读懂华夏千年的脊梁！”
  * *技巧*：古人智慧（民族自豪感） ➔ 痛点承接（看不懂古建） ➔ 图解大书（降低门槛促单）。

## 四、视觉双轨制：破除“AI假人油画感”

经过多次实验对比，**纯AI生成视频在真实文化垂直领域是行不通的**。必须采用“双轨制”：

```
                    ┌── 首页 Hook 包装大图 (GPT 史诗雾气悬崖大殿)
                    │
   视觉双轨策略 ─────┼── 正片核心骨架 (100% 真实历史摄影/梁思成测绘图/实景壁画)
                    │
                    └── 尾页 CTA 转化 (GPT 3D悬浮斗拱爆炸图 + 中文典藏艺术大书实拍)
```

### 1. 首尾使用 GPT/DALL-E 打造视觉奇观
* **首页封面（图 1~5）**：
  * 画面要求：中国山西太行山巅的悬崖唐代大殿，苍茫云海，真实摄影质感，8k 纪录片画质。
  * 包装处理：底层加黑色半透明渐变蒙版，文字采用**华文行楷（STXINGKA.TTF）128pt 烫金渐变字**，副标题配合鲜红印章底块。
* **尾页转化（图 33~39）**：
  * 画面要求：纯正中国古代木构斗拱 3D 悬浮力学爆炸图（Exploded Diagram），带有发光的榫卯受力分解箭头。
  * 带货图书：古色古香的案几上摊开的精美大画册，左页斗拱剖面、右页永乐宫朝元图壁画，**全中文排版，严禁任何英文符号**。

### 2. 正片主体 100% 使用实景高清照片
* **佛光寺**：真实航拍实景、殿前经幢与雄伟出檐。
* **崇明寺断梁殿**：真实的千年老旧木梁原状、顺栿串拼接暗榫细节特写。
* **崇福寺弥陀殿**：真实殿内空间、减柱后的人字斜拱与金代佛造像。
* **永乐宫**：三清殿实景外观与《朝元图》神祇壁画原画高清扫描件。
* **效果收益**：极大提升视频的可信度与专业权威感，避免了“AI流水线滥造假图”的廉价感。

## 六、运镜渲染：FFmpeg 动态镜头组算法

静态图片直接展示会非常呆板，必须通过算法赋予图片**平滑的影视级运镜（Ken Burns Effect）**。我们在 `build_rhythmic_subtitles.py` 中实现了 5 组镜头动力学公式：

### 运镜模式与 FFmpeg 滤镜参数

```python
def build_vf(motion_type, total_frames):
    # 画幅：1080x1920 (9:16)
    w, h = 1080, 1920
    if motion_type == "push":
        # 缓慢推进：从 1.0 放大到 1.12，中心聚拢
        return f"scale=8000:-1,zoompan=z='min(zoom+0.0006,1.12)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d={total_frames}:s={w}x{h}:fps=25"
    elif motion_type == "pull":
        # 缓慢拉远：从 1.12 缩放到 1.0，展示宏大全局
        return f"scale=8000:-1,zoompan=z='if(lte(zoom,1.0),1.12,max(1.001,zoom-0.0006))':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d={total_frames}:s={w}x{h}:fps=25"
    elif motion_type == "tilt_up":
        # 仰拍摇镜：视线从下往上扫过大殿与屋脊
        return f"scale=8000:-1,zoompan=z='1.10':x='iw/2-(iw/zoom/2)':y='ih-(ih/zoom)-(on/{total_frames})*(ih-(ih/zoom))':d={total_frames}:s={w}x{h}:fps=25"
    elif motion_type == "tilt_down":
        # 俯拍摇镜：视线从房梁缓缓滑到地面立柱
        return f"scale=8000:-1,zoompan=z='1.10':x='iw/2-(iw/zoom/2)':y='(on/{total_frames})*(ih-(ih/zoom))':d={total_frames}:s={w}x{h}:fps=25"
    elif motion_type == "pan_right":
        # 水平移动：移步换景，横穿大殿中央
        return f"scale=8000:-1,zoompan=z='1.10':x='(on/{total_frames})*(iw-(iw/zoom))':y='ih/2-(ih/zoom/2)':d={total_frames}:s={w}x{h}:fps=25"
```

* **镜头组逻辑**：
  * 宏大佛光寺 ➔ `tilt_up`（仰视，体现国宝巍峨感）；
  * 房梁拼接暗榫 ➔ `tilt_down`（俯视探究内部秘密）；
  * 走入弥陀殿 ➔ `pan_right`（横移，呈现中堂空旷）；
  * 3D斗拱爆炸图 ➔ `push`（推近，细致观察力学流向）。

## 七、字幕排版美学：中老年高转化短句爆发

根据中老年用户的眼球追踪习惯和实际反馈，**长字幕（一整行十几二十字）留存极差**。必须采用“短句爆款字幕”：

### 1. 核心排版规格
* **短语单屏字数**：每次屏幕仅停留 **5 ~ 9 个字**，卡点同步。
* **字体字号**：加大加粗！微软雅黑 / 苹方特粗体，字号加大 30%（剪映参数 `size=13.5`，FFmpeg 参数 `FontSize=26`）。
* **配色方案**：
  * **字面**：纯白高亮（`PrimaryColour=&H00FFFFFF`，RGB 255, 255, 255）。
  * **描边**：纯黑实心重描边（`OutlineColour=&H00000000`，`Outline=4.5`，`BorderStyle=1`）。
  * **阴影**：关掉杂乱阴影（`Shadow=0`），黑白对比极为干净凌厉，在暗色和亮色背景下均一清二楚！
* **黄金安全高度**：
  * 居中下部（垂直位置约 **65% 屏幕高度**，剪映参数 `transform_y = -0.28`，FFmpeg `MarginV=560`）。
  * **关键设计原因**：完美避开手机端抖音、视频号底部的**作者昵称、文案区、小黄车带货入口**，同时避开右侧的点赞、评论、转发按钮！

## 八、剪映专业版全自动草稿注入底层实现

为了实现无需人工手动拖入素材、对齐音画、加字幕，我们通过 Python 的 `pyJianYingDraft` 库，实现了**代码级直接写盘生成剪映草稿工程**。

### 1. 草稿目录定位
剪映电脑端草稿统一保存在：  
`C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft`

### 2. 注入核心脚本模板 (`01_一键注入剪映专业版草稿.py`)

```python
import os
import pyJianYingDraft as draft
import pymediainfo

# 1. 初始化剪映草稿工程
JIANYING_DIR = r"C:\Users\Miche\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft"
DRAFT_NAME = "【带货二创】山西古建三大奇迹_短句爆款字幕版"
folder = draft.DraftFolder(JIANYING_DIR)
script = folder.create_draft(DRAFT_NAME, width=1080, height=1920, fps=30, allow_replace=True)

# 2. 创建主轨道
script.append_track(draft.TrackSpec(draft.TrackType.video, name="画面轨"))
script.append_track(draft.TrackSpec(draft.TrackType.audio, name="解说配音轨"))

# 3. 爆款大白字纯黑描边样式
text_style = draft.TextStyle(
    size=13.5,
    bold=True,
    color=(1.0, 1.0, 1.0),
    border=draft.TextBorder(color=(0.0, 0.0, 0.0), width=4.5),
    align=draft.TextAlign.center
)

# 4. 遍历 39 个短句分镜，卡点注入三轨
cur_us = 0
pause_us = int(0.10 * 1_000_000)

for idx, c in enumerate(CLAUSES):
    # 解析音频时长
    aud_path = c["audio_path"]
    media_info = pymediainfo.MediaInfo.parse(aud_path)
    dur_sec = float(media_info.tracks[1].duration) / 1000.0
    dur_us = int(dur_sec * 1_000_000)
    
    # 视频切片
    v_seg = draft.VideoSegment(c["img"], draft.Timerange(cur_us, dur_us + pause_us))
    script.add_segment(v_seg)
    
    # 音频切片
    a_seg = draft.AudioSegment(aud_path, draft.Timerange(cur_us, dur_us))
    script.add_segment(a_seg)
    
    # 短句字幕（位于下部 65% 黄金交互安全区）
    sub_seg = draft.TextSegment(
        c["text"],
        draft.Timerange(cur_us, dur_us + pause_us),
        style=text_style,
        clip_settings=draft.ClipSettings(transform_y=-0.28)
    )
    script.add_segment(sub_seg)
    
    cur_us += dur_us + pause_us

# 5. 保存工程
script.save()
```

* **收益**：打开剪映 Pro，工程列表里已经躺着剪好、配好音、对齐好大字描边字幕的完整时间线。只需人工加一段舒缓的古风古筝 BGM，即可直接导出！

## 九、实战避坑与关键经验汇总

### 1. 软件环境与文件占用锁避坑
* **剪映 SQLite 锁**：如果剪映 Pro 打开并停留在此工程上，剪映会锁死 `deepagent.db`。如果此时运行脚本覆盖草稿，会抛出 `WinError 32 另一个程序正在使用此文件`。**解决方式：注入草稿前必须关闭剪映，或在代码中为每次生成的草稿名增加后缀**。
* **Windows 路径与编码陷阱**：Windows 的 `cmd.exe` 默认是 GBK (CP936)。所有 `.bat` 启动脚本如果保存为无 BOM 的 UTF-8，中文字符会被 cmd 切割导致语法崩溃（如 `'Downloader"' 不是内部命令`）。**解决方式：在 Windows 底层通过 `mklink /J` 建立纯英文 ASCII 映射通道 `D:\fuye\tools`，bat 文件严格使用 GBK 编码保存**。

### 2. 平台风控与采集避坑
* **抖音主页防爬**：未登录直接抓取博主主页，抖音会报 `403 Forbidden` 并触发滑动验证码。必须在 `settings.json` 中配置一次登录 Cookie，或仅抓取单条无水印链接。
* **视频号封闭机制**：全网没有任何纯靠一个网页链接就能离线爬取微信视频号的工具。必须依赖电脑版微信在打开博主主页时派发的密钥。**最省力的做法：花 10 秒在博主主页向下滑动翻页，让微信下发作品列表，然后点击【后端批量下载】由工具在后台全自动并发解密并导出互动数据**。

### 3. 硬件性能考量（Meteor Lake / Intel Arc 平台）
* 当前机器搭载 Intel Core Ultra 5 125H（集成核显，无独立 NVIDIA CUDA 显卡）。
* **技术决策**：杜绝本地直接运行几十 GB 的重度 PyTorch/CUDA 深度学习生图模型。TTS、运镜合成、视频压制全部基于轻量高效的 **ONNX Runtime (`sherpa-onnx`)、Edge-TTS 和 FFmpeg 硬件加速**，出片渲染仅需十几秒，流畅丝滑。

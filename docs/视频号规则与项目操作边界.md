### 3.4 AI、剧情、内容使用与直播

- **AI及演绎（R1 §6.4）**：生成或合成的非真实音视频，以及剧情演绎的虚构内容，应显著标识，避免混淆。标识不使虚假营销、侵权、危险或低俗内容合法化。
- **标识的补充依据（R3）**：第3条覆盖生成合成的文本、图片、音频、视频、虚拟场景；第10条要求发布者主动声明并使用服务方的标识功能，禁止恶意删除、篡改、伪造、隐匿标识。办法自2025-09-01施行。项目不得以“平台可能自动识别”为由省略主动操作。
- **权利与传播（R1 §6.5）**：上传不转移知识产权、肖像权等，但协议包含腾讯及合作场景使用、用户分享引用编辑展示等安排，部分场景可设置。素材许可应覆盖实际上传和使用方式；只获私人学习或有限展示许可，不能直接推定可用于带货传播。
- **未成年人（R1 §6.6）**：相关姓名、肖像、声音、行为等需取得适当权利人同意，并考虑平台按协议使用处理的范围。项目采用核验监护人授权和必要性、减少可识别信息的做法。
- **直播（R1 §6.7）**：另适用[直播功能使用协议](https://weixin.qq.com/cgi-bin/readtemplate?t=finder_live_privacy&lang=zh_CN)和[直播行为规范](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/QP3B5JAHbc1MzpPm)。本次未对这两份专项文件逐条审读；本文不能作为直播开播审核完成的依据。

## 4. 本项目后续怎样执行

以下为**项目执行约定**，条款号说明其来源，不把更具体的流程冒充平台原话。

### 4.1 账号与工具

1. 使用真实主体控制的账号。简介写实际内容方向；未核实的专家、机构、官方或品牌关联不写。单独通用名词或地域名不作为拟定账号名的默认方案（R1 §3—4）。
2. 剪辑、字幕、素材整理等本地离线处理可以继续作为制作方式；这与接入微信系统是不同问题。软件“能运行”不代表已获平台许可（R1 §4.3）。
3. 对需登录微信、读取或拦截通信、自动操作账号、采集平台数据、自动评论或发布的第三方工具，先核对平台书面许可、官方接口和适用条件；未核实前不启用新的接入任务。现有下载器、证书代理和历史采集记录均不能作为许可证明；本文也没有完成其合规认证。
4. 自动化可用于本地制作和审核辅助；外部发布仍按用户授权和平台允许方式执行。不得做刷量、互刷群、虚假买家评论或规避审核。投放和平台正规推广另按相应规则核实，不能与刷量混为一谈（R1 §4.5、4.7）。

### 4.2 选题与事实

1. 优先选可证实的建筑机制、器物用途、历史地理问题。每条核心事实回到原书页、机构资料或可信原始来源；网页标题和AI回答不单独作为结论证据（R1 §5.4—5.5）。
2. 分清确定事实、学术解释、争议观点、传说与创作情节；口播中保留影响理解的限定。例如“有研究认为”“当地流传一种说法”，且这些限定本身有来源。不能给无依据故事加“据说”就发布。
3. 避免把建筑形制推成招财、改命、镇邪的真实功效。民俗或信仰可作有据、客观的文化说明；不渲染灵验、恐吓或提供运势指导（R1 §5.13）。
4. 具体新闻、活动或现时状态标清时间。旧材料不当最新发现；不能用虚构专家、密闻、被封杀等制造悬念（R1 §5.5、5.14）。
5. 医疗、养生治病、投资荐股、法律服务等不纳入当前文史图书内容的默认生产范围；若另做此类内容，先核验对应资质和专项规则。书籍品类不自动豁免内容要求（R2 §10）。

### 4.3 文案、标题与互动

1. 标题提出正文能回答的具体问题，封面展示正文实际涉及的对象。正文把关键机制讲完，再自然接到相关书（R1 §5.11；R2 §6.4—6.5）。
2. 不使用虚假卖惨、诅咒、民族或身份绑架、奖励换互动。不用“点赞才告诉你”“关注下集揭答案”“评论领取不能兑现的福利”等设计（R1 §4.4、5.10；R2 §6）。
3. 可以围绕真实内容提问或邀请观点；不把正常留言做成刷评论任务，不承诺互动带来好运、收益或商品效果。
4. 不保留竞品独特开头、转化段和完整叙事再局部换词。参考的是问题、事实和表达方法，最终重新组织论证与结构（R1 §5.3；R2 §2）。
5. 名人引语核到原始出处，营销中出现人物还要核对对应权利及使用方式。无法证明时改为自己的解释，不能只去掉引号继续暗示出自名人。

### 4.4 图像、音频与AI素材

1. 按镜头记录来源、权利人、许可范围和凭据。自有、已获许可、明确可商用或符合适用法定使用条件的素材，才按其具体范围使用。网上公开可见、购买图书、截图、标注出处，都不自动等于商业传播授权（R1 §5.3、6.3、6.5）。
2. 古代作品与现代照片、扫描、注释、排版的权利分开判断；实拍也要遵守场所拍摄及商业使用要求，涉及人物和展品等时另核对。已有合法授权在有效范围内沿用。
3. AI可以辅助氛围、概念和机制示意。精确结构、地图、文物细节不能凭生成结果认定为事实；关键几何、方向、构件和文字回到核验资料（R1 §5.4、5.11、6.4）。
4. 非真实画面、复原及演绎在对应场景显著说明，如“AI生成示意”“复原示意”“情景演绎”，并使用发布端适用的AI声明功能；不能把小字藏在末尾代替清晰告知。具体标签及入口以当次发布页面为准。
5. 真实图书封面、版次、内页和赠品用对应实物或商家合法提供的对应资料，不用AI编造商品；“AI示意”也不能掩盖商品不一致。
6. 配音用本人、商用许可音色或已获适当授权的声音；不擅自克隆名人、教师、专家声音制造推荐。AI合成配音也进入标识核对范围；不因画面实拍就漏审声音。
7. 音乐、字体、图片和声音分别核许可；去水印、镜像或变速不能取得许可。不得以规避识别为目的删改标识（R1 §4.7；R3）。

### 4.5 画面质量与同质化

1. 每个镜头服务一个口播信息；讲清淤不配无关古城远景，讲结构不拿AI奇观作真实证据（R1 §5.11、5.14）。
2. 保留正常可读字幕；避免用全屏大字轮播、海报拼接和重复素材代替内容。字幕存在不等于违规，判断的是覆盖方式、完整性、信息与观看体验。
3. 五镜结构、统一字幕或品牌风格可作制作组织方式，不是平台认可的安全模板。换城市名、换音色、换背景图后批量发布近似内容，不作为原创增量（R1 §5.12）。
4. 静态图加运镜、AI配音、无人出镜等形式未在本次规则中被一概禁止；也没有“几张图”“几秒一切”即安全的数字门槛。每条都须有独立问题、必要证据和真实信息增量。
5. 手机端检查画面、字幕、音乐和配音，确认没有缺字、卡顿、黑边、花屏、突断或明显不同步；购买引导与实际挂载及按钮状态一致（R2 §15）。

### 4.6 图书、广告与交易

1. 延续[双层书目](../05_爆款知识库与复盘/10_双层书目与15城映射.md)：后台研究书证明事实，前台挂售书另核商品。不能把参考PDF的章节、插图、作者、奖项、装帧说成另一商品拥有。
2. 核对实际挂载的书名、作者、出版社、ISBN、版次、册数、封面及目录。缺证据可以继续草稿，但不承诺“这本书详解本机关”“图中全部内页就在该书”等具体卖点。
3. 价格、券、赠品、库存和截止时间按当次真实活动核验；不能沿用历史口播价格或编造限量、全网最低、销量、用户评价及效果（R1 §4.6.4；R2 §4.11）。
4. 知识分享附购买方式也要核对广告识别。商业推广显著标明广告，并使用平台适用的推广声明；本项目不以“挂了购物链接”单独证明所有标识要求已完成（R2 §9.6）。AI标识、广告标识、演绎标识各自解决不同问题，不能互相替代。
5. 商品与主题自然相关；不用无关热搜、箭头诱导、虚假平台背书或私下成交引流替代真实商品介绍（R2 §4.13、8、13）。
6. 书籍卖点描述内容、阅读用途和实际特点；不承诺治病、提分必达、改运、暴富或购买后的确定性人生效果。作者名、专家身份或推荐语有据，也不自动产生代言许可。
7. 供应方合法经营、商品真实及适用商品资质需要核验；若自己开店、上架、发货或直播，再查对应当前规则。此处是项目审核动作，不把未读取的商城专项要求写成已验证的细则。

## 5. 典型表达与替代做法

以下均为项目示例，不是平台逐字示例或绝对判词。替代说法也须有事实和许可支持。

| 不采用的做法 | 风险 | 可采用的方向 |
| --- | --- | --- |
| “这座古宅能改变全家财运” | 运势宣传、伪科学 | 介绍宅院朝向、排水或采光的实际构造 |
| AI生成建筑特写，称“现场实拍，千年原貌” | 非真实画面冒充事实 | 有据示意并标识，真实细节用对应实拍或获许可资料 |
| “不转发就不是中国人”“点个赞给家人积福” | 煽动、道德绑架、迷信式互动 | 提问观众是否观察到某种构件及用途 |
| “答案下集说，关注才知道” | 本条结果不揭晓、诱导关注 | 本条讲清一个问题；下一条独立讲另一个问题 |
| “某大师亲口推荐”，配克隆声音 | 虚构推荐、声音及身份权利 | 使用获许可音色，以自己的身份说明有据卖点 |
| 引用参考书图示，挂另一书称“这本都有” | 商品不一致、虚假宣传 | 挂售书目录未核实时只写独立知识草稿 |
| “刷到的都买了，今天最后十套” | 虚构销量、稀缺性 | 根据实际页面说明真实规格、活动及适用条件 |
| 竞品视频裁剪换字幕，再用同钩子同结尾 | 搬运洗稿；形式变化不能产生权利 | 独立研究同一问题，重写结构并配合法素材 |
| 全程书封海报加购物车箭头 | 低质及不当推广案例风险 | 有内容增量的讲解，清晰广告声明，相关真实商品展示 |
| 文史知识视频引向私人二维码“领资料再买书” | 站外及联系方式风险、诱导 | 使用平台允许、与当前内容相关且经过核验的交易路径 |
| “仅供参考”后继续讲食疗根治 | 医疗及虚假功效，免责声明不足 | 当前项目删去诊疗、用药及疗效建议 |
| 十条稿只替换城市名、配音和背景图 | 近似编造同质化内容 | 每条独立问题、证据和机制；没有增量先不批量 |

## 6. 审核、留证和异常处理

### 6.1 什么时候检查

| 阶段 | 检查重点 | 结果 |
| --- | --- | --- |
| 选题前 | 账号方向、专业资质、真实性、是否诱导或违规选题 | 能否继续研究，哪些说法不用 |
| 文案定稿 | 核心事实、引语、标题兑现、原创结构、商品关联 | 事实来源及待补内容 |
| 素材入库 | 图像、音色、音乐、字体、人物许可和AI用途 | 素材台账，缺权利则替换 |
| 成片预览 | 音画、字幕、低质、同质化、AI及演绎可识别 | 按成片确认，不能只看文案 |
| 实际发布前 | 当日商品、价格活动、广告及AI功能、链接和账号权限 | 填[发布审核卡](视频号发布审核卡.md)，人工最终确认 |
| 发布后 | 作品状态、处罚通知、投诉和真实互动 | 有异常先核实通知及原因，保留证据再处理 |

每项填写“通过 / 不通过 / 待补证 / 不适用”。通过须有材料或实际检查依据。相关项不通过或待补证时，不给“可以发布”结论；不影响不依赖该项的研究、草稿和替代素材工作。无需把后台台账和全部审核文字念进口播。

### 6.2 每条应保留的证据

记录作品ID、稿件版本、发布日期、关键事实来源与页码、素材来源及许可、音色和音乐许可、AI及演绎用途、挂售商品及活动信息、发布标识与链接检查结果、最终确认人。涉及变化的信息保留当时页面截图或导出；商品、授权或素材一变，对应审核重做。

本仓库公开。账号证件、联系方式、订单个人资料、授权合同中个人信息、后台敏感截图和登录凭据不提交公开仓库。公共台账只保留不敏感的结论和证据编号，原件放受控位置。原始竞品视频继续按项目约定不上传。

### 6.3 收到处罚或投诉后

1. 先保存通知、作品ID、原稿、成片及当时的授权和商品材料，查清针对哪项行为；不要用播放变化代替处罚证据。
2. 暂停重复发布或扩散同类问题内容，定位是否涉及同一素材、模板、引语或商品。按平台通知纠正或下架；不改码、镜像、换号重发来对抗处理。
3. 有事实或许可证明的，按处罚页要求提交申诉，说明争议点及对应证据；无依据的内容先纠正。不得伪造授权、身份、时间和销量。
4. R1 §7.3给出的反馈路径：视频号绑定微信 → 发现 → 视频号 → 右上角人像 → 创作者中心 → 创作者服务 → 帮助与反馈 → 意见反馈；或微信 → 我 → 设置 → 帮助与反馈 → 视频号 → 意见反馈。界面变化时以当前客户端为准。
5. 把已确认问题及纠正方式写入本项目复盘；不能把一次申诉成功概括为某种违规做法永久可用。

## 三、口径澄清：实际可用的是 E2-F5-TTS，不是 GPT-SoVITS / ElevenLabs

方案 A 原文写的是「喂给 GPT-SoVITS 或 ElevenLabs」。**仓库里并没有这两者的代码、依赖或模型目录**，实际已经落地并跑通的是另一条同属零样本克隆的技术路线：

| 项 | 实际情况 |
|---|---|
| 引擎 | **E2-F5-TTS**（通过 `gradio_client` 调用公共 ZeroGPU 空间 `mrfakename/E2-F5-TTS`） |
| 费用 | **免费、免 API key**（公共推理空间，不产生 MiniMax 那种按字计费） |
| 依赖 | `gradio_client`、`imageio_ffmpeg` —— **本机已安装** |
| 形态 | `(参考音频, 参考文本, 生成文本)` 三元组：给一段人声 + 它逐字对应的文字，克隆出同一条声线 |
| 已验证 | `scripts/clone_wangliqun_tts.py` 用它产出过 `王立群_主音色基准/`，本批次 dry-run 通过 |

**所以：不要去找 GPT-SoVITS / ElevenLabs，直接用 `clone_voice_ztts.py`（E2-F5-TTS）。** 若将来用户明确要求换引擎，那是另一件事，本说明不覆盖。

## 四、参考音频与参考文本（最容易出错的一步）

### 4.1 授权红线（先读这段）

| 音频 | 能否做克隆参考 | 理由 |
|---|---|---|
| `01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav` | ✅ **可以** | 我们自己账号的成片音轨，方案 A 原本就指定它 |
| `01_配音与音色库/王立群_主音色基准/voice_wangliqun_sample.mp3` | ✅ 可以 | 已有克隆基准（真人公开节目音频，用途另议） |
| `02_公共资产库/竞品口播人声_20261116-17/` 下 13 条 | ❌ **绝对不可以** | 竞品作品的一部分，克隆它等于复刻他人声音权 |
| 任何未获授权的第三方录音 | ❌ 不可以 | 同上 |

> **本任务产出的竞品分析结果，其价值在"手法参数"（节奏、句长、语速、音高区间），不在音频本身。**
> 竞品那 13 条只允许用于内部对分析与参数标定；**不进成片、不做克隆参考、不进任何恢复包**。

### 4.2 参考音频怎么切

零样本克隆的参考音频**建议 5~15 秒**清晰单人人声。方案 A 指定的 `voice_master.wav` 是 **5 分 27 秒**的整条音轨，**不能整段直接喂**——太长会音色漂移。脚本用 `--ref-start` / `--ref-duration` 自动切：

```bash
--ref-audio "01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav" \
--ref-start 30 --ref-duration 8
```

切点建议避开片头片尾、避开音乐最响处，挑一句**语气平实、无强调、无情绪起伏**的地方（该片是知识讲解型口播，中段任取 8 秒通常可用）。

### 4.3 参考文本必须逐字对应

参考文本 = 参考音频**那一段在说的原话**，一个字都不能差。对不上，克隆出的音色会明显漂。

**已确认的对应关系**（靠短 ID 绑定，精确匹配）：

| 项 | 值 |
|---|---|
| 参考音频 | `01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav`（源视频 `20261015·中国十大"带孙辈长见识"的历史名城《下集》`，短 ID `146e49fa`） |
| 对应文案 | `05_爆款知识库与复盘/爆款作者口播文案库/02_锦绣千秋录+食力过日子_文案TXT/食力过日子_11篇/2026-10-15_20-42-31_20261015·中国十大＂带孙辈长见识＂的历史名城《下集》_146e49fa_xWT111.txt` |
| 绑定依据 | 文件名里的短 ID `146e49fa` 与参考音频源视频短 ID **完全一致** |

**取参考文本的操作**：打开上面那个 TXT，用 `--ref-start` 对应的位置，在文案里找到**同一句**，逐字抄进 `参考文本.txt`。

- 若 `--ref-start 30` 落在某句中间，就把该句**完整**写进参考文本，同时把 `--ref-start` 前移一点，让这整句落在片段内；
- 拿不准就多试几个起点，每次只改 1~2 秒；
- **参考文本与音频对不上，是这个方案最常见的失败原因**，务必先验证再批量合成。

## 五、执行步骤

### 步骤 1：切分预检（不发起任何合成，先看节奏对不对）

```bash
python scripts/clone_voice_ztts.py \
  --ref-audio "01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav" \
  --ref-start 30 --ref-duration 8 \
  --ref-text "参考文本.txt" \
  --script "03_视频成片与工程/<项目名>/01_文案与分镜/口播文案.md" \
  --out-dir "scratch/clone_dryrun" \
  --chunk-min 18 --chunk-max 40 \
  --dry-run
```

`--dry-run` 只切句与检查参考片段，**不调用 E2-F5-TTS、不产生任何外部请求**。看两件事：
1. 切出的每段是不是语义完整、没有腰斩词组；
2. 平均字数/段是不是落在 18~40（对应竞品的短句快切节奏）。

### 步骤 2：正式克隆合成

去掉 `--dry-run`，把 `--out-dir` 换成正式目录：

```bash
python scripts/clone_voice_ztts.py \
  --ref-audio "01_配音与音色库/对标原声参考/食力过日子_带孙辈长见识_下集/voice_master.wav" \
  --ref-start 30 --ref-duration 8 \
  --ref-text "01_配音与音色库/方案A克隆音色_20261119_竞品节奏_v01/参考文本.txt" \
  --script "03_视频成片与工程/<项目名>/01_文案与分镜/口播文案.md" \
  --out-dir "01_配音与音色库/方案A克隆音色_20261119_竞品节奏_v01" \
  --chunk-min 18 --chunk-max 40 \
  --name "食力克隆声线_竞品节奏"
```

- **逐段独立合成**，脚本带断点续跑缓存（缓存键含参考音频 SHA + 参考文本 + 生成文本），中断后重跑不会重复请求；
- 段级失败会重试 3 次；**全部段都成功才会拼母带**，有失败段落则只写 `生成记录.json` 并以非零码退出，不产出残缺母带；
- **免费，不需要费用确认**；不调用 MiniMax，不产生任何计费请求。

### 步骤 3：接剪映草稿

克隆母带落到 `01_配音与音色库/<输出目录>/voice_master.mp3` 后，按既有极速管线接草稿：

```bash
# 把母带拷进工程配音目录
copy "01_配音与音色库\方案A克隆音色_20261119_竞品节奏_v01\voice_master.mp3" "03_视频成片与工程\<项目名>\03_配音音频\voice_master.mp3"

# 生成剪映草稿（读音频、自动卡点、切分镜头、BGM 淡出与标题）
python scripts/fast_draft_pipeline.py init --dir "03_视频成片与工程/<项目名>"

# 视觉素材就绪后秒级热替换
python scripts/fast_draft_pipeline.py apply-images --dir "03_视频成片与工程/<项目名>"
```

> `fast_draft_pipeline.py` 会校验配音参数哈希；直接替换 `voice_master.mp3` 而不改 `voice_meta.json` 可能触发重合成。克隆母带的正确接法是：**把克隆母带当作配音成品直接进草稿**（草稿只认音频与时长），若管线要求重合成，则改用 `--voice`/`--rate` 走 Edge 路线，**不要**用 Edge 覆盖掉克隆母带。

## 六、叠加竞品手法参数（本次分析的新增结论）

克隆只解决"像谁"，**节奏要另外调**。竞品主簇（7 条共用同一音色）实测：

| 参数 | 竞品主簇实测 | 落到本任务怎么做 |
|---|---|---|
| 平均句长 | **1.70 – 2.50 秒** | `--chunk-min 18 --chunk-max 40`（约 8~14 字/秒） |
| 语速 | **30 – 41 段/分** | 文案本身要短句化；E2-F5-TTS 无语速参数，靠句长控制 |
| 停顿 | 几乎无长停顿 | 文案按标点切，别写长定语从句连排 |
| 基频 F0 | 150 – 175 Hz（中位 ~155） | **不可控**：克隆音色 F0 由参考音频决定。若参考音频 F0 明显偏低，参考片段换一段或换参考源 |
| 慢派对照 | v06 老王阅书 24.7 段/分、句长 3.14 秒 | 若要慢派，把 `--chunk-min/max` 放大到 28~55 |

**F0 这一项要单独说清**：克隆音色继承参考音频的音高，参数调不动。如果目标是 F0 ~155 Hz 的中青年沉稳男声，就得**选一条 F0 接近的参考音频**，而不是靠参数。

> 竞品主簇 F0 150~175 Hz 是「中青年男声」区间；本仓库「食力过日子」参考音频属中老年讲解型，**两者音色路线不同**。这是有意为之的取舍——我们用授权素材做声线，用竞品的手法参数做节奏，**不追求"同款音色"**。

## 七、输出与复用规则

沿用 `docs/Antigravity_六角色定稿配音交接_2026-11-07.md` 第 6 节：

```text
01_配音与音色库/方案A克隆音色_20261119_竞品节奏_v01/
├── 参考片段/                  # 实际切出的参考音频（克隆用）
│   └── voice_master__30s_8s.wav
├── 干声WAV/chunk_001.wav …    # 每段独立干声
├── 干声MP3/chunk_001.mp3 …
├── voice_master.wav           # 拼接后的完整母带（WAV 是真解码产物，不是改后缀）
├── voice_master.mp3           # 母带 mp3（320k）
├── 生成记录.json              # 每段文本/参数/SHA/时长/状态 + 母带 SHA
├── concat_list.txt
└── 参考文本.txt               # 与参考片段逐字对应的文本
```

硬规矩：

- **所有素材先保留干净人声**，不自动加 BGM、不加音效；混音由下游管线做（人声 +3.0 dB、BGM −13.0 dB、末尾 2.5 s 淡出）。
- **不用旧流程的 15 秒截断母版**。需要 15 秒成片时单独交付裁剪版，完整声音要保留。
- 缓存依据含参考音频 SHA、参考文本、生成文本、引擎；**参考文本一改就是新音色，必须新建版本目录**，不能仅凭同名文件跳过或覆盖。
- 每段记录：文本、状态、SHA-256、时长、引擎、参考片段路径与 SHA、参考文本。**不记录也不输出任何密钥**。
- 路径一律从项目根推导，**禁止写死盘符或用户名**。

## 八、验收与交付

### 8.1 文件检查（脚本内已做一部分，Antigravity 需复核）

- 可解码，无漏句、无截断、无重叠；
- 段数 = 期望段数，失败段为 0；
- 母带时长 ≈ 文案预期朗读时长；
- `生成记录.json` 中每段 SHA 与实际文件一致。

### 8.2 人工试听（必须，不能跳过）

- **音色一致性**：把 `干声WAV/` 各段连着听一遍，确认没有明显"换人"（E2-F5-TTS 逐段独立合成，段间音色会漂，这是本方案的固有风险）；
- **是否像参考源**：与参考片段对照，判断是否达到预期；
- **节奏是否达到竞品区间**：平均句长是否落在 1.7~2.5 秒量级、是否短句快切；
- **听感自然度以用户听感为准**，文件检查通过 ≠ 音色可用。

### 8.3 交付给用户的报告要写清

本次哪些段落成功/失败、克隆母带位置、参考音频与参考文本来源、实际段数与平均段长、**人工试听是否已确认**、以及失败段落需不需要重跑。

## 十、常见故障与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 克隆音色明显不像参考 | 参考文本与音频对不上 | 改 `--ref-start`，用 TXT 里逐字对应的那句重做 |
| 音色偏糊/带电流 | 参考片段本身有 BGM 或压缩伪影 | 换一段干净的；必要时先做降噪/重采样 |
| 段与段之间像换人 | 逐段独立合成的固有漂移 | 减少段数（放大 `--chunk-max`）或人工试听后挑用；不要靠重试解决 |
| 脚本报 `参考片段过短` | `--ref-duration` 太小 | 调到 5~15 秒 |
| `gradio_client` 连接超时 | 公共 ZeroGPU 空间负载高 | 等几分钟重试；脚本按段缓存，不会丢进度 |
| 母带缺失但生成记录里有 failed | 有段落三次重试仍失败 | 修好参考文本/网络后重跑同一命令，成功段会命中缓存 |
| `fast_draft_pipeline` 重新合成了配音 | 配音参数哈希校验触发 | 确认 `03_配音音频/voice_meta.json` 的哈希与实际配音来源一致，别用 Edge 覆盖克隆母带 |

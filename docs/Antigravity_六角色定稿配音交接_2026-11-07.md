## 3. 收费边界与调用方式

- 本次交接不发起任何付费合成。
- 后续用户提供台词并要求生成时，先简短说明该批 MiniMax 普通文字合成的预估费用，再执行该批；不需要重复询问已经确认的六个声音。
- 五个 MiniMax 系统音色没有额外的音色设计费，生成新台词仍按平台文字合成计费；不能说整套永久免费。爷爷走 Edge，不调用 MiniMax。使用时按官网当日价格估算，保留 API 返回的 `usage_characters`，不能把估算说成实际账单。
- 不把 MiniMax Code 签到积分、桌面套餐余额与开放平台 API 余额混在一起；直接使用已配置的开放平台 API。
- 连接信息读取本机 `config/voice_api/config.yaml`，密钥可复用 `resolve_api_key()`，环境变量优先。不要输出密钥，也不要把含密钥的运行配置写入文档或公开仓库。
- 只读取旧配置中的 API 连接、模型、音频格式、超时等必要字段，再合并定稿角色。场景只使用本次用户给的台词；输出使用新目录。不要沿用旧场景的 `out_dir`。

## 4. 每次新台词怎样处理

用户可以这样输入：

> 男宝，兴奋又好奇：“爷爷！爷爷！你看，我嘴冒烟了！”
>
> 爷爷，笑着接话：“哟，再呼一口，爷爷看看。”

执行步骤：

1. 整理本批清单：每句有固定 `id`、场景 `scene`、角色 `role`、台词 `text` 和表演方向 `direction`。表演方向单独保存，不要作为台词朗读。未经用户要求，不改原话。
2. 从定稿 JSON 加载角色参数；台词只能调表演相关参数，不能覆盖 `engine`、`voice_id`、`edge_voice`。缺少角色、出现未认识的角色就先指出，不猜音色。
3. MiniMax 复用 `voice_api_tts.py` 的 `synthesize_minimax()`；爷爷复用 `synthesize_edge()`。复用函数，不直接运行旧脚本的默认全量入口。
4. 每句单独合成干声，记录原始合成参数。MiniMax 收费请求前落下“已提交”记录，成功后记录返回用量、trace_id、文件哈希。网络超时、结果不明时停止该句，不自动重新提交；已明确成功的句子不重复付费。
5. 先交付本次需要的短钩子和接话。只有用户要求扩展时才扩大台词量，不自动制作全部历史情绪库。
6. 混音和文件检查通过后，给用户可直接播放的干声、对话版和试听页。最终表演是否自然，以用户听感为准。

**不要直接使用旧示例中的 `--role ... --text ...` 来做单句任务。** 当前旧入口会把匹配角色的多条历史台词都替换为同一段文字，可能造成重复调用；`skip_existing` 又只按文件名判断，可能错误复用旧音色。应先建立只有本批台词的新任务清单，或补上明确的单句/任务清单入口后再运行。

## 5. 表演与情绪

目标是生活化的家庭对白，短视频开头要有情绪、反差和接话感。音色固定不等于每句话都用同样的语气。

- 男宝：兴奋、追问、委屈，避免每句都尖叫。
- 女宝：天真、好奇、告状，保持用户选中的原音色。
- 爸爸：急躁、无奈、缓和，避免每句都像正式演讲。
- 妈妈：责备、压火、哄孩子，避免把“责备”一律做成喊叫。
- 爷爷：逗孩子、关心、解释。Edge 没有与 MiniMax 相同的情绪控制接口，用标点、短句与小幅语速调整表达，不承诺精准哭腔或怒气。
- 奶奶：关心、接话、护短，保持用户选中的B音色。

MiniMax 平常可省略 `emotion` 让模型按文本表达；需要强调时，先核对当前模型支持的值再使用。不要沿用旧文档里的 `neutral` 作为未经验证的默认值。`sad` 不等于无奈喊冤，`fearful` 不等于心疼。先用已选基准音调，避免通过大幅变调把角色改成另一个声音。

情景对话先交付一个自然版本；用户明确要更强情绪时，只重做对应句子。不要默认每句生成多个收费版本。

## 6. 输出与复用规则

新任务另存，例如 `01_配音与音色库/家庭对白_<日期>_<主题>_v01/`，代码从项目根目录推导路径。

建议包含：

```text
台词与表演方向.json
干声MP3/<台词ID>_<角色>.mp3
干声WAV/<台词ID>_<角色>.wav
场景对话/<场景ID>.mp3
开始试听.html
生成记录.json
文件清单.json
```

原有V1、V2、V3试听和六角色定稿样本都保留。WAV 是实际解码转换得到的文件，不把 MP3 改后缀冒充 WAV。

- 所有素材先保留干净人声，不自动加 BGM、音效；对话版可以拼接。
- 可复用 `assemble_voice_test.py` 的 `build_sequence()` 顺序拼接完整 WAV。不要使用旧流程的15秒截断母版；需要15秒成片时，单独交付裁剪版并保留完整声音。
- 对话接话间隔可先用约180—300毫秒；急促争执可约80—150毫秒，再按实际听感调整。
- 缓存依据应包含文本、引擎、音色ID、模型、情绪、速度、音调、音量及音频设置。参数变化要新建版本，不能仅凭同名MP3就跳过或覆盖。
- 保存每句参数、来源、SHA-256、时长、用量和完成状态。检查可解码、无漏句、无截断、无重叠；试听页使用实际存在的相对音频路径。

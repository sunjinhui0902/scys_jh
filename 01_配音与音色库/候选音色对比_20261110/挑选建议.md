## 一、先看这两个数：f0_hz 和 cps

- **f0_hz** = 中位基频（自相关估计）。老年男声实际约 **95–130 Hz**，老年女声约 **165–220 Hz**。这是"像不像老人"最直接的物理线索。
- **cps** = 每秒字数。同一条对照句台词完全相同（18 字），所以 **cps 差就是语速差**，可直接横向比。

> 重要边界：基频只是物理特征，**不等于听感好坏**。"慈祥还是刻薄""自然还是装腔"仍要人耳判断。本文档把**已实测数据**和**我的主观判断**分开标注。

## 二、三个由实测得出的硬结论

### 结论 1：Edge 的 pitch 参数在中文语音上几乎不改变基频

| 音色 | pitch 设置 | 实测基频 | 变化 |
|---|---|---|---|
| Edge Yunyang | -6Hz → -6Hz（仅语速 -18% → -26%） | 127.0 → 123.1 Hz | -3% |
| Edge Yunjian | -10Hz → -14Hz | 108.1 → 102.3 Hz | -5% |
| Edge Xiaoxiao | -9Hz → -14Hz → -16Hz | 231.9 → 227.1 → 228.6 Hz | 基本不变 |
| Edge Xiaoyi | -6Hz → -12Hz → -10Hz | 296.3 → 285.7 → 290.9 Hz | 基本不变 |

**含义**：Edge 音色想"变老"，真正的杠杆是**语速（rate）**，不是音调（pitch）。
所以 Edge 家族里那几档"深度老化"其实是**同一个音色 + 不同快慢**，不是三种音色。

### 结论 2：MiniMax 的 pitch 有效，但有音色自身的下限

`Gentleman` 在 pitch -5 / -8 / -6 三档下，基频都稳定落在 **98.2 Hz**——说明这个音色的"低沉度"已经到底，再往下压不会更低，只会变闷。

### 结论 3：中文女声普遍比老年女性偏年轻

所有 Edge 女声基频在 **227–296 Hz**；MiniMax 女声里 `Mature_Woman` 266.7 Hz、`Sweet_Lady` 275.9 Hz、`Kind-hearted_Antie` 238.8 Hz。真正落进老年女性区间的只有三个：
`Wise_Women` **207.8**（当前版）、`Kind-hearted_Elder` 再压低 **202.5**、`News_Anchor` 压低 **220.7**。

## 九、本包的方法与已知限制

- 引擎：MiniMax `speech-2.8-hd`（用户自有 API Key，计费字符 959，对应本轮新增部分）+ Edge `edge-tts`（免费）。
- Edge 不支持 emotion 参数，情绪只能靠语速/音调近似，这是 Edge 候选的固有短板。
- `f0_hz` 由自相关估计，会受嗓音沙哑、情绪（生气时音高上冲）影响；情景行的基频普遍高于对照行，属正常现象，不代表音色变了。
- 指纹相似度 >0.97 判定为"同音色不同语速/参数"，不判定为"同一文件"；字节级重复已单独检查并清零。
- 音频可解码、无削波、响度已列在体检表；但**"像不像一家人""像不像老人"这类判断，本文档只给出数据倾向，没有替代人耳试听**。

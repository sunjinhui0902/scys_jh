# 参考图书到视频号

生产稿先读根目录下 `05_爆款知识库与复盘/09_带货内容执行标准.md` 与 `10_双层书目与15城映射.md`。当前15城稿、字幕与五镜需求在 `03_视频成片与工程/15城纠偏稿_2026-10-16_v2/`，旧图文包与首轮3稿保留研究版本。B01～B04只作后台史料，前台从M01～M04选择商品方向；目录证据支持后再写具体章节卖点。

从本文件位置向上找到项目根目录。先读根目录AGENTS.md，并使用项目已有wechat-channels-book-commerce处理内容创作。统一入口为 `05_爆款知识库与复盘/城市与图书知识库/README.md`，按城市、主题、事实、选题和文案检索；书目入口为 `02_公共资产库/参考图书/README.md`。日期只标识各历史批次，新增资料另开批次。针对北京、西安、洛阳、大同、平遥、苏州、杭州、泉州、丽江、敦煌、承德、曲阜、南京、安阳、登封，先查知识库的城市索引，再读原15城批次对应档案。

可用 `python scripts/build_reference_knowledge.py --search 泉州` 检索255条来源记录（原225条＋本轮15稿与15机制记录）；用 `--kind fact`、`--kind topic` 或 `--kind script` 限定。110条历史选题记录包含90题与首轮20卡，未跨批去重。来源与生产状态分别保留。更新索引运行默认模式，交付前用 `--check` 校验；仅支持脚本明确配置的来源。

## 按任务做需要的工作

- 选题：有城市专题时先读该城档案，按事实ID和选题ID继续；75条事实与90题是15城批次的独立资料，不并入竞品验收计数。需要回原书时查 `05_爆款知识库与复盘/参考图书拆解_2026-10-15/城市章节索引.csv`，结合该目录的 `01_四书拆解.md` 选择书与章节。214行是首轮文件的目录定位记录，不是214个已深读主题。
- 补证据：优先核对原PDF的目录、版权页及目标正文。扫描件使用根目录 `scripts/reference_books.py` 的inventory/ocr/show；安装说明见该批次 `04_GitHub技能选型与复用.md`。未安装OCR时仍可渲染阅读少量页面，不以空文字层断言书无内容。
- 写稿：先明确观众的一个疑问，提取二到三个必要事实解释机制。15城完整包同步交口播、21～31句5～9字字幕及五镜需求；只补事实或改一句时按实际请求交付。短句不拆坏专名和语法；时长以试读或配音核准，短句文本还需音频对齐生成时间码。
- 引书：明确区分研究参考书与实际在售SKU；只在版本、目录或内页支持时描述商品内容。不清楚商品也能先完成内容稿。

## 保留证据边界

每个事实记录书目ID、原件SHA-256、PDF阅读器页序、可读的纸书页与章节；无法读清纸书页时留空，不推算冒充。换扫描版本后重新核对页差。

OCR仅辅助检索，数值、专名、年代与双栏断句要看原图。分别记录“有书页支持”和“已用独立来源核实”，不要把同一编委会两册算成独立证据。史地旧书的行政区划、人口、排名、价格、开放信息不默认当前有效。

叙事类材料区分史实、传说、作者游记与文学想象。跨书存在不同数字时保留各自口径，未核清则避用。书中艺术风格描述不自动等于现存建筑的全部建造年代。

## 可复用输出

简单请求直接交付需要的卡片或稿件。新批次按需保存：

- 书目与实际读取范围；明确目录、OCR、人工抽读各完成多少。
- 选题卡：城市、疑问、来源页、事实转述、原创开头、画面需求、需要补核的内容；机器数据同步保存JSONL。
- 完整口播与对应镜头；事实来源留后台文档，不把核查流程念进口播。

沿用项目“说书式口播写法”的场景进入和单点发现，不复制既有示例句子。没有实测数据时称候选或试读稿。

原PDF不改名、不移动。OCR原文和页面图像仅放被忽略的 `.local/reference-books/`；公开仓库只保存简短事实定位和原创分析。修订另存批次，保留旧证据。按项目同步约定仅保存本任务结果。

## 交付前快速核对

确认页码指向正确文件；口播中的每条历史事实能回指书页或独立来源；未读章节不被描述为已读；没有把传说、旧数据、商品卖点升级为已核事实。脚本新增或修改后实跑当前场景，并检查缓存不会串用源文件。最终给出可点击的结果文件链接。

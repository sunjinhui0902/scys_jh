# 提示词库

以下模板是执行框架，不要求逐字使用。

## 授权素材信息提取

```text
你将收到一份我有权处理的音频、视频或文字素材。请只提取可听见或可见的信息，不总结，不补写。按段输出原文；听不清处标记[待确认]；人物、时间、地点、数字和引语单独列入事实核验表。不要把推测写成事实。
```

## 原创文案重构

```text
根据事实台账和商品资料，从零设计一篇面向指定受众的原创内容。不得沿用参考作品的独特开头、句序、段落结构、比喻、结尾或购买引导；不得只做同义词替换。所有事实必须能回指来源，未核验内容删除或加限定语。先给出2个结构方案，再输出选定方案的完整成稿和事实引用表。
```

## 分镜

```text
把成稿拆成镜头。每个镜头必须包含：编号、对应文案、叙事目的、主体与动作、景别与构图、素材来源或生成方式、字幕、预计时长、权利状态。切分以完整叙事单元为准，不机械按字数切分。
```

## 视觉提示词

```text
根据每个镜头生成一条独立视觉提示词，包含时代、地点、主体、动作、构图、景别、光线、色彩、质感和画幅。禁止文字、水印、商标、伪造新闻现场、未授权公众人物肖像和容易被误认为真实证据的画面。每条提示词与镜头编号一一对应。
```

## 发布前审查

```text
审查这份内容包。分别检查事实、版权、肖像、声音、AI标识、商品信息、营销表达、虚假互动和账号权限。每项输出通过/不通过/待补证、证据和修正动作。任何项未通过时，不得给出“可以发布”的结论。
```

## 数据诊断

```text
根据账号历史基线和本轮数据，按曝光→3秒留存→完播→互动→商品点击→转化→退款的漏斗定位主要掉点。先排除权限和违规信号，再提出下一轮只改变一个主要变量的测试方案。不要承诺流量或收益，不用固定播放量阈值武断判断换号。
```
